# 与你相恋

<img src="assets/icon.png" alt="与你相恋插件头像" width="144">

为 N.E.K.O 的日常聊天加入好感、恋爱关系、专属称呼和共同回忆，让相处的变化留在每一天里。

**当前版本：0.9.28** · 插件标识：`love_with_you`

[使用指南](docs/guide.md) · [问题反馈](https://github.com/qaqms/n.e.k.o_plugin_love_with_you/issues) · [开发文档](docs/development.md)

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 好感与关系 | 概览优先显示关系阶段、好感进度和纪念日，可展开今日变化和共同经历。支持共用或独立好感，以及 30 / 90 / 365 天走势 |
| 告白与专属称呼 | 根据关系阶段调整聊天语气和称呼，设置偏好名字与禁用称呼；可选开启角色主动告白 |
| 纪念日 | 记录相识日、在一起的日子和自定义纪念日；可预览并确认导入宿主历史中的相识日期 |
| 礼物商店 | 商店首屏显示钱包和可领取金币，展开「今日相伴」领取奖励；购买礼物并选择角色赠送 |
| 共同经历 | 一起听歌、看屏幕、写便签或约好以后关心。可开启桌宠自动感知或宿主「一起看」进度追踪，在关系概览按角色查看 |
| 我们的小屋 | 3D 微缩客厅。从沙发直接看向唱机或茶几上的双人杯，翻小屋日历，用投影幕续看，也能写便签、回看回忆和陈列礼物 |
| 立绘与外观 | 固定或随机展示立绘，自行导入图片，调整主题色和深浅模式 |
| 立绘互动 | 从关系概览点击立绘，打开抚摸、背包和同行游戏。内置立绘按姿势预设抚摸区域，鼠标移到可抚摸处会变成手掌光标 |
| 同行游戏 | 与角色一起探索林地，学习技能、选择路线、挑战首领，保存后继续旅程 |

## 安装与开始

1. 获取发布的 `.neko-plugin` 安装包，在 N.E.K.O 插件管理器中导入并启用「与你相恋」。
2. 打开插件面板，查看「关系概览」，在「设置」中选择共用或独立好感，并调整显示偏好。
3. 正常进行文字聊天，插件会自动判断好感变化并记录进度。
4. 需要模型参与判断时，在宿主「Plugin API」中为「好感判断」绑定模型；不绑定也可使用。

源码开发加载方式见[开发说明](docs/development.md)。各项设置、操作步骤和规则详见[使用指南](docs/guide.md)。

## 相处规则

- 默认使用本地关键词判断好感；自动判断每轮最多变化 3 点，每天聊天增加最多 4 点，送礼增加最多 4 点。
- 默认好感达到 80 后，仍需在聊天中确认双方心意才成为恋人；已有恋爱关系不会因近期好感下降而自动取消。
- 主动告白和好感随时间变淡均可选开启，默认关闭。角色的具体表达取决于宿主聊天模型。
- 聊天达标后需在商店手动领取金币；金币仅用于插件玩法，不涉及充值。
- 「清零好感」保留恋爱关系；「重新开始关系」需要确认，会清除当前恋爱确认和在一起日期，保留相识日、历史、偏好与商店资产。

## 同行游戏

从左侧「专属称呼」下方进入「同行游戏」。玩家操作旅人，同行者自动跟随与支援；支持技能成长、九段旅程、精英和首领挑战，以及局外永久强化。

- 键盘使用 WASD 或方向键移动，学习主动技能后用 Q / E 施放；触屏提供虚拟摇杆和技能按钮。
- 支持暂停、保存并返回和继续旅程；切页或失焦会暂停。提示控制权由其他页面持有时，可确认接管。
- 冒险进度与金币独立保存，不改变好感，也不兑换礼物商店金币；战斗不调用模型。

**当前版本为测试版，非正式版。** 游戏暂为中文，内容、平衡和表现仍会调整。

## 数据与隐私

关系、纪念日、便签、钱包、外观和自定义立绘保存在宿主分配的本机插件数据目录。安装包不携带用户存档，更新代码时请保留原数据目录，重要进度建议先备份。

插件在内存中读取近期聊天进行判断，不另存完整聊天记录。未绑定「好感判断」模型时，评分在本机完成；绑定后，当前轮和上一轮的有限对话内容会经宿主发送给所选模型。主动告白、送礼回应和便签共创使用宿主聊天模型。

「共同经历」只在你主动开启后保存对应草稿与确认内容，可查看、编辑、删除或停止后续引用；删除插件内记录不会清除已进入宿主聊天历史的文字。完整保存范围见[使用指南的隐私说明](docs/guide.md#隐私)。

## 常见问题

**必须额外绑定模型吗？** 不需要。本地好感判断开箱可用；告白、送礼回应与共创使用宿主已有的聊天模型。

**切换独立好感会清空记录吗？** 不会。共用关系和各角色记录分别保留，称呼与日期偏好也会保留。

**为什么聊天或送礼后没有立即回应？** 提交请求不代表模型已生成或播放回复；请查看面板状态，结果不确定时使用原操作的核对或重试入口。

**如何反馈问题？** 提交 Issue 时说明插件与宿主版本、复现步骤和错误提示。日志或截图请先隐去密钥、聊天隐私和个人信息。
