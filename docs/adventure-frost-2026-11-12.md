# 0.8.0：技能精研与冰系配合

日期：2026-11-12。实现下一阶段计划的第一批：原有八招完善、冰针、霜爆和凝霜碎冰。

## 学习与控制

新局使用战斗规则 3，十招由同一份 JSON 供前后端读取。玩家仍有三个自动、两个主动槽；同行两个自动、一个支援槽。共享经验按玩家、玩家、同行分配成长，最高 31 级，两次共用重选。冰针是双方都可学习的自动技能，霜爆是玩家主动技能，进入按学习顺序确定的 Q / E 槽，不增加键位。

每招沿用 1 级学会、2 级威力或节律、3 级互斥分支、4 级精研、5 级觉醒或合法复合。研习页展示当前分支、下一节点、同角色融合前置与每人最多一项复合的限制。图鉴按本局规则显示，旧局不出现冰系候选。

| 技能 | 分支与满级变化 |
| --- | --- |
| 火丸 | 连焰精研加弹；爆裂扩大、延长灼烧区；本系觉醒加弹；旋焰弹首次命中扩散一次 |
| 迅斩 | 横扫精研加距离，疾斩再缩短间隔；觉醒扩大扇形；疾风斩追加一道贯穿风刃 |

| 回势斩 | 反击独立冷却由 5 秒降至 4 秒；解围加强击退；觉醒覆盖一整圈 |
| 焰环 | 余焰延时、炽环扩圈；觉醒再扩大并延长 |
| 破阵突进 | 贯阵距离 180 → 240、半宽 60 → 80，精研至 90；觉醒半宽再加 15；稳进精研加盾 |

| 冰针 | 凝霜每击两层，以威力与间隔作代价；双棱增加弹体；精研延长标记，觉醒增加贯穿并继续延长 |
| 霜爆 | 裂霜消费既有凝霜追加伤害后挂一层；霜雾每秒少量伤害、挂一层；觉醒半径 145、爆发挂三层，覆盖裂霜原本的一层 |

霜雾初始持续三秒，精研四秒；落地爆发仍独立造成伤害。区域第一次更新即触发首个雾伤害，此后每秒一次；暂停不推进时钟。觉醒与复合弹体使用独立贴图、范围线与短时特效，仍使用本地原创轻量素材。

## 凝霜与碎冰

- 标记最多三层，基本持续三秒；冰针精研、觉醒逐步延长至五秒。重复命中刷新持续时间，不无限累加层数。
- 普通敌人每层减速 12%；三层冻结 0.6 秒，冻结触发后 3.5 秒内不能再次冻结。首领每层仅减速 4%，永不冻结。
- 玩家迅斩、回势斩、突进的直接命中可消费全部层数，每层追加 12 基础伤害；首领追加收益乘 0.65。伤害仍经过玩家攻击加成。
- 碎冰有全局 0.6 秒、每目标 1.8 秒冷却。同次范围剑技不会无限碎冰多个目标；普通弹体、追加风刃和持续区域不触发。
- 同行贡献过当前凝霜时，消费标记记为一次同行配合；混合叠层保留同行贡献，消费或过期后重新计算。霜爆裂霜的消费不记入剑技碎冰次数。
- 碎冰次数、其中的同行配合、双方伤害在局内和结算显示。伤害按实际承受量累计。

状态集中在 `frost.mjs`，保存目标、来源、层数、过期时间、冻结结束、冻结免疫、目标碎冰冷却与全局冷却。标记最多 160，弹体最多 160，区域最多 12，短特效最多 16；目标死亡清除标记。后端拒绝未知字段、无效来源、死目标引用、超限层数和过长未来时钟。

击败首领立即停止当前多目标攻击的后续伤害与状态修改，终态显示和保存使用同一份贡献事实。

## 保存兼容

冒险文件升级至 v4，支持原有 v1/v2/v3。读取不写回，首次成功迁移写入前保存唯一文件名备份，不覆盖之前的备份。钱包和永久强化沿用原规则，战斗不调用模型，不改变好感或礼物经济。

旧规则 1/2 的进行中旅程仍按原规则继续；规则 2 使用独立的 `skills-v2.json` 与原数值，不会因升级获得新候选或更宽的突进。新开局才使用规则 3。规则不能在单局中切换，v3 文件不能伪装携带规则 3。没有旧存档自动清空或把新状态硬塞入旧快照的处理。

规则 3 保存凝霜时钟、霜雾下次伤害、弹体形态、双方独立构筑与待选项；读取不重抽、不重置免疫，不因恢复而再次发金币。所有演示与测试使用独立目录，不读写真实角色存档。

## 验证与交付边界

验证覆盖真实升级卡学习、E 键霜爆、同行冰针物理命中、剑技碎冰归属、无目标保留冷却、首领免冻、霜雾周期、两种冰系分支与觉醒、保存恢复、旧目录及原几何参数。原八招另检查全圆斩击、突进宽度、四目标牵引、首次命中扩散及疾风追击。保留原有经济防重、保存响应丢失、接管和升级确认回归。
