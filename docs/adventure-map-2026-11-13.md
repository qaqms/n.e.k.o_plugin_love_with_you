# 0.8.3：林地层次与障碍

## 场景与走位

地面、小径、铺装和投影留在地表。树干、树冠、岩石、石柱、残墙与石台散石使用独立对象，按落地点与角色脚底的纵坐标排列。角色经过物件前方时显示在前，经过后方时被遮挡；遮住玩家或同行的树冠淡化至 38%，较高的石制物件淡化至 60%。树干保持不透明。

林地固定布局包含 44 棵树、2 根石柱、6 段残墙、6 块岩石和 12 块石台散石。碰撞只覆盖树干、墙基和石块的接地范围，不使用整张图片或树冠的边框。石台保留四个宽入口；地表与阴影不阻挡移动。

新旅程使用战斗规则 5，固定对应本版布局。玩家、同行和全部敌人都会与障碍碰撞。同行优先寻路，距离较远时加速追赶，不通过瞬移穿过障碍。敌人与同行共用本地 A* 库绕行。目标有直线路径时直接移动；否则复用最多 900ms 的路线，在目标明显移动时提前重算，每帧总共最多重算 4 条。导航网格按身体尺寸缓存，以较保守的余量留出转弯空间，不切过障碍的角。

突进、击退和敌人冲锋使用同一组障碍进行扫掠，截停在障碍之前。突进的伤害只覆盖实际经过的路段；完全受阻时不消耗冷却。冲锋预警从生成时就显示截短后的路径，保存与恢复仍保留这条预警，不重新瞄准。弹体命中障碍后消失；近战和自动索敌也核对遮挡。

地面法术可以隔着障碍落在目标位置，爆炸与领域范围不做建筑掩体判定。经验结晶的掉落点会移至可用位置；进入拾取范围后的吸附允许越过障碍。这些规则与实体的走位碰撞分开处理。

敌方危险提示保持在场景物件与友方特效上方。简化特效不关闭碰撞、导航或危险提示。

## 存档兼容

冒险文件升级至 v6，读取 v1–v5；第一次升级写入前，按原版本保存完整备份。钱包、永久强化、当前角色身份和已保存的构筑保持。

规则 1–4 的进行中旅程继续使用原有的无障碍通行规则，不在中途增加碰撞。其画面使用新的物件排序；结束旧旅程并重新出发后才启用规则 5。进行中不能改写规则版本。

规则 5 的布局由规则版本固定，不单独保存随机障碍或导航缓存。读档时，若玩家、同行或敌人的位置落入碰撞体，则确定性地移至附近安全点；这一恢复不读取随机数，不改写生命、经验、击败数、技能、冷却或已触发标记。再次保存和读取应保持相同结果。寻路、地表装饰与遮挡显示都不消费战斗 RNG。

## 模块与依赖

- `static/terrain-rules.mjs`：固定布局、接地碰撞几何、安全落点、线段扫掠与图层常量。
- `static/forest-map.mjs`：Phaser 静态碰撞体、实体放置、A* 路线缓存与重算预算、脚底排序与遮挡淡化。
- `static/forest-art.mjs`：地表及物件纹理；不进行碰撞或伤害结算。
- `static/combat.mjs`、`encounters.mjs`：技能与冲锋通过地图服务确定实际落点，伤害仍由战斗规则决定。

随包本地发布 `javascript-astar 0.4.1`，通过 `tools/game/package-lock.json` 锁定；运行时不访问 CDN。原始源码、作者与 Binary Heap 来源注释随文件保留，MIT 许可在 `static/engine/ASTAR-LICENSE.txt`。重建命令为 `npm --prefix tools/game ci` 和 `npm --prefix tools/game run build`。
