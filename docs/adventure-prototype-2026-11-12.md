# 边境林地：第一阶段战斗原型

适用版本：0.7.6。完成规划中的承载接入与初步战斗，不代表完整首章已经制作完毕。

本文保留 0.7.6 原型的实现与验证记录。0.7.7 已补充冒险金币、局外属性商店、原价退还与 v1 存档迁移，当前规则以 `adventure-economy-2026-11-12.md` 为准。

## 当前可玩内容

- 原有关系面板旁增加独立「边境林地」静态面板；不修改宿主。
- 选择实际宿主角色作为同行，玩家与同行分别选剑卫或元素使。
- 俯视 2D 战场、玩家移动、自动攻击、同行跟随与自动攻击、护盾支援、三种普通敌人。
- 共用经验、八类升级、每次提供三个选择；有可用的同行升级时至少提供一项。
- 当前为 20 分钟时限的原型波次，18 分钟出现最终首领；击败、失败、时间耗尽或主动结束均保存结果。
- 当前关系阶段在开局固定为同行 0–8% 支援加成，不增加或扣除好感。
- Phaser 3.90.0 随包发布，附 Phaser 与内嵌 EventEmitter3 的许可；原创 SVG 游戏角色与程序场景不依赖原图库。
- 本版本战场界面暂为中文，原有八种语言的界面键与插值检查保留。

## 操作

WASD 或方向键移动，攻击和同行支援自动执行。点击右上暂停按钮或按 Esc 暂停；移动设备提供左下方向摇杆。升级时选择一项成长后继续。

暂停页可继续、保存并返回或明确结束。保存并返回必须收到确认，成功后释放控制。另一页签可继续未被控制的冒险；还在其他窗口控制的冒险需要明确接管。

窗口失焦或隐藏后暂停，不自动恢复。浏览器或宿主意外退出时从最后成功保存的检查点恢复，不能保证最后一帧。直接刷新并未释放旧窗口的控制，需要明确接管；正常保存并返回则无需接管。

## 存档边界

冒险数据单独保存在 SDK 数据目录的 `adventure.json`，不写关系或礼物钱包。

保存全局修订、本局 ID、单调局序号、同行身份、开局职业与阶段快照，以及模拟时间、随机状态、生命、技能等级、升级待选项、敌人、弹体、经验掉落和冷却。内存控制权与启动 epoch 不持久化；插件重启后需重新取得控制。

自动检查点在游玩约十秒后安排，也在出现升级候选与选定升级后安排。保存请求串行提交；失败暂停并保留原请求。确认上次操作必须核对请求 ID、操作、局 ID、修订与保存时间，不能把 HTTP 成功直接当作保存成功。

最多保留 32 条回执；即使旧回执淘汰，原请求仍受单调修订、当前局身份与终态约束，不能重新打开旧局。文件版本未知或结构损坏时只阻止冒险，不覆盖旧文件，也不阻止原有关系面板工作。

这是本地单人原型，检查点结构和上限校验不等于竞技防作弊。当前没有永久冒险资产，也不宣称可以抵抗本机用户修改游戏代码或存档。

## 当前不包含

冒险金币、局外属性购买与退还、第三流派、精英与小首领的完整节奏、约 24 项分支/协同、纪念物、归来模型交流与共同经历草稿，均留在后续阶段。现有结果页只记录已经发生的游戏事实，不虚构发放奖励。

原型的敌人密度、技能收益、好感加成与 20 分钟节奏未经完整真人试玩调优。当前不是已验收的性能版本，没有用户机器与真实宿主并行负载的帧率结论。

## 开发与独立试玩

安装并复制固定版本引擎：

```powershell
npm --prefix tools/game ci --ignore-scripts
npm --prefix tools/game run build
```

启动独立试玩服务器：

```powershell
& '../N.E.K.O/.venv/Scripts/python.exe' -B tools/adventure_preview.py --port 4322
```

默认使用系统临时目录；需要跨服务器重启保留测试存档时，显式传入仓库外的 `--data` 测试目录。该服务器只监听本机，不加载宿主插件、角色模型或真实存档。预览中的 YUI/MIO 是固定测试身份。

浏览器回归：

```powershell
$env:NEKO_UI_DEPS='D:\neko kaifa\.neko-ui-review'
$env:NEKO_UI_BROWSER='C:\Program Files\Google\Chrome\Application\chrome.exe'
npm --prefix tools run test:adventure
```

回归启动独立临时服务器与真实 `AdventureStore`，不使用 LocalStorage 冒充落盘；通过与宿主静态面板相同的请求消息名称连接。它验证通信合同与游戏逻辑，不代替导入真实宿主的完整集成验收。

## 验证范围

- 独立状态规则：启动/重放、保存失败不发布内存、控制释放和接管、旧 epoch、修订并发、回执淘汰、终态、未知版本和非法快照。
- SDK 编排：冒险不改变关系或礼物状态、读取实际阶段、停用后拒绝、启动后拒绝旧 epoch。
- 浏览器：实际 canvas 与素材、键盘移动、Arcade 碰撞、同行击败敌人、升级暂停、生命/敌人/RNG/技能恢复、丢失保存响应、失焦、死亡终态、390px 摇杆、待选升级恢复、接管及最终首领。
- 原关系面板继续运行原有类型、多语言与浏览器回归。

此轮不自动安装或重载运行中的插件；导入包用于玩家主动验收。
