# 0.7.8：双角色技能构筑首批实现

日期：2026-11-12。设计依据为 `adventure-build-redesign-2026-11-12.md`。

本批实现双方独立成长、八个基础技能、玩家按键技能、两条同行接续和两项复合进化。不代表 18 技能扩充目录或完整首章已经完成。

## 开局与操作

| 角色 | 开局路线 | 自动攻击 | 主动或支援 |
| --- | --- | --- | --- |
| 玩家 | 火术 | 火丸 | 焰环，默认 Q |
| 玩家 | 突击剑 | 迅斩 | 破阵突进，默认 Q |
| 同行 | 引风术 | 风刃 | 自主引风 |
| 同行 | 守护剑 | 回势斩 | 自主岩甲 |

默认配对为火术与引风术。WASD / 方向键移动，自动选择攻击目标；Q / E 释放已学的主动技能。第二个主动技能学习后按顺序进入 E，读档不打乱顺序；触屏有两个技能按钮。

当前键位固定为 Q / E，键位重映射仍待后续提供。失焦、隐藏、升级和暂停会停止模拟并清空按键；这些状态下不能施放主动技能。进攻法术没有目标时不消耗冷却；突进朝当前或最后的有效移动方向执行，有地图边界限制。

## 成长与构筑

- 共用经验，团队 1–31 级，升级所需经验为 `14 + 当前等级 × 7`。
- 从等级 2 开始，研习归属依次为玩家、玩家、同行；最多 20 次玩家研习、10 次同行研习。
- 当前屏的三个选项全部属于该角色。连续等级在一次暂停流程中逐项处理，不转换成长归属。
- 玩家最多三个自动技能、两个按键技能；同行最多两个自动技能、一个支援技能。主攻击包含在自动槽位内。
- 玩家与同行均可学习合法自动副技能；玩家可学习另一开局路线的主动技能。支援槽的起始技能本批不提供替换。
- 每局两次共用重选，剩余次数、候选、保底与随机状态均进入检查点。
- 有已学可升级技能时优先提供一项强化，有空槽时优先提供一项新招。已达分支节点但连续两次未展示时，下次保底展示该技能的分支。
- 满槽、互斥、满级或前置不足的招式不进入可选池；完成技能后仍有有限的通用强化可选。
- 成长选定后先确认保存再恢复战斗。失败保留窗口和原请求，重试不会再应用一次升级。

技能为 1–5 级：1 级学会；2 级选择威力或节律；3 级选择行为分支；4 级精研；5 级本系觉醒或满足条件的复合进化。

| 技能 | 两条互斥分支 |
| --- | --- |
| 火丸 | 连焰：双发且单枚减伤；爆裂：命中留下短时灼烧区 |
| 迅斩 | 横扫：扩大斩区；疾斩：更快、单击略弱 |
| 风刃 | 贯风：增加贯穿；散风：扇形三发且单枚减伤 |
| 回势斩 | 反击：玩家受击后追加有限反击；解围：扩大斩区并击退普通敌人 |
| 焰环 | 余焰：延长持续时间；炽环：扩大范围和伤害 |
| 破阵突进 | 贯阵：增加距离和沿途打击；稳进：获得少量护盾 |
| 引风 | 接续牵引：响应焰环；巡猎旋流：扩大自主聚敌范围 |
| 岩甲 | 及时覆甲：响应突进并加强护盾；震荡护甲：施放时追加周围伤害 |

迅斩与回势斩使用近身扇形命中，不再作为短射程弹体表现。风刃保存已命中目标，恢复后不会对同一目标再次算作首次贯穿。

## 两条接续

### 火术与引风

玩家成功施放焰环，在目标位置留下持续火区。同行引风已到 3 级且选择“接续牵引”、技能就绪、距离及目标合法时，立即向该火区牵引最多三个普通敌人。首领不被强制拉动。

### 突击剑与守护剑

玩家成功突进后，同行岩甲已到 3 级且选择“及时覆甲”、技能就绪且距离合法时，立即覆甲。未达到条件时，不排队在稍后追放。

两者都消耗支援本身的冷却。接续直接绑定一次实际成功施放，不由每次弹体命中或持续伤害触发，也不再产生新的接续起手。普通自动支援仍保留；接续分支的自主支援在冷却就绪后留出 1.5 秒响应窗口，之后按自身条件施放。

反击有独立 5 秒冷却，攻击间隔最低 250 毫秒，护盾最高 200。不新增模型调用、真实桌宠动作、宿主点击区域或聊天消息。

## 复合进化与图鉴

- 同一角色火丸 4 级 + 风刃 2 级，可将火丸进化为旋焰弹。
- 同一角色迅斩 4 级 + 风刃 2 级，可将迅斩进化为疾风斩。
- 主招升至 5 级并替换表现；风刃保留。每个角色最多一项复合进化，仍可以选择普通本系觉醒。
- 另一角色的技能不作为自己的进化前置，双方通过接续配合。
- 暂停页与研习页均可打开技能图鉴，预览角色可用技能、互斥分支、复合条件与前置保留结果。

结果页列出双方技能、实际伤害、支援次数与接续次数。这些由战斗规则累计，不由模型评价或虚构。

## 存档和经济

冒险文件版本升级为 3；单局 `rules` 单独保存。已有 v1/v2 存档在读取时先只迁移内存，在首次写入前创建唯一的 `adventure.v1-*.backup.json` 或 `adventure.v2-*.backup.json`。

旧局保留规则 1，包括旧局尚无检查点的情况；继续使用原来的混合升级池和自动攻击。新界面新开局使用规则 2。兼容旧调用端未携带 `rules` 的开局请求，将其明确记为规则 1；不允许中途切换规则。未知或非法版本保留原文件并阻止冒险写入。

新快照保存双方技能与槽位顺序、专精、分支、进化、冷却、待选归属、候选、重选、保底、随机状态、面向、范围效果、贯穿命中及贡献。没有离线战斗或按真实时间补算冷却。

冒险钱包、四项永久属性、免费退还、进行中商店只读、整分钟 ×6 与通关 +80 的结算不变。永久攻击对双方造成的技能伤害生效；不将攻击强化错误应用为岩甲永久护盾加成。好感仍使用开局的同行强度快照，不额外改变冷却或锁定必要接招。

## 模块与预算

- `static/skills.json` 为前后端共用的声明式目录；不是可执行存档脚本。
- `skills.mjs` 负责合法构筑、升级与候选，`combat.mjs` 负责效果和接续，`study.mjs` 负责显示。
- `_adventure_skills.py` 校验新快照；`_adventure.py` 保留控制、修订、原子写入、迁移与结算职责。
- 仍沿用 Phaser 与既有原创角色素材。新斩击、火区和牵引使用有限的引擎图形。
- 最多 160 弹体、12 持续区域、16 短时反馈。区域达到预算后仅在同类、同归属、同规模组内合并；短时灼烧不会移动已有的大火区。
- 新战斗不在每帧请求 Python、写存档或调用模型。预算不等于已完成真实宿主的帧率验收。
