# 怪物卡通化与攻击动作（开发步骤 0.9.7，随发布版本 0.9.2 推出，规则与存档不变）

2026-11-16。项目主人认为怪物改成和新地图一致的卡通风格会更好，并确认了概念图（`foe-sprite-source\cartoon\concept-foes-lineup.png`、`concept-foes-poses.png`）和动作方案。

## 改了什么

### 新造型

八种怪物全部重画成粗描边、颜色鲜亮、大眼睛的卡通风格：叶芽史莱姆、幽火灵、蛮猪、疾角兽、荆芽术士、苔甲卫士（石头魔像）、荆棘咏者（玫瑰祭司）、林地守望者（鹿角树人）。画面比原来大约大 15%，更好辨认。

### 动作

每种怪物一张 16 格的动作表：

| 格 | 内容 |
| --- | --- |
| 0–5 | 待机与移动：一颠一颠的压扁、拉伸 |
| 6–7 | 蓄力（发抖） |
| 8–9 | 出招 |
| 10–11 | 受击 |
| 12–15 | 死亡：压扁、淡出 |

- **蓄力**：跟着遭遇战 AI 的蓄力状态走。疾角兽、荆芽术士、苔甲卫士、荆棘咏者、林地守望者开始蓄力时，就换成蓄力动作。
- **出招**：蓄力结束、真正出手的那一刻，播放约 0.3 秒的出招动作，并配上对应特效：
  - 蛮猪、卫士、首领：一圈冲击波加碎石
  - 疾角兽：扬起尘土
  - 史莱姆：一圈绿色水花
  - 其余：一闪亮光
- **接触攻击**：史莱姆、幽火灵、蛮猪没有蓄力，贴身打到你时播放出招动作，同一只怪每 0.25 秒最多一次。
- **朝向**：怪物会转身面向玩家。

## 怎么做的

- 每种怪物让 AI 在同一张图里画出待机、蓄力、出招、受击四个姿势，保证造型一致。按形状把四个姿势切出来，统一缩放，再用脚本烘焙成 16 格动作表（`static/art/foe-<种类>.png`）。原图和提示词在 `foe-sprite-source\cartoon\`。
- `foe-art.mjs` 的 `FOE_SHEETS` 改为新格子大小和新动作分段。`battle-art.mjs` 新增 `motionOf`、`lunge`、`strikeFx`。`adventure.mjs` 在玩家被接触伤害时调用 `lunge`。
- **只改画面**：碰撞体积、伤害、速度、出招时机都不变。压扁拉伸是烘焙在图里的，不改精灵缩放，所以碰撞框不会跟着变。规则版本仍是 17，存档版本仍是 18。

## 验证

- 新增浏览器用例：八张表都是 16 格；蓄力、出手、恢复时的画面帧正确；接触时播放出招；面向玩家；碰撞体不变。
- 重跑了美术动画、受击反馈、顿帧、精英与守关、怪物贴图等 10 项旧用例，全部通过。
- 截图检查了八种怪物在待机、蓄力、出招三个状态下的样子。

## 没做的

- 移动仍然是原地压扁拉伸，没有真正的迈步动作。
- 首领转阶段没有专属动作，只有原来的提示文字和援兵。
- 没有在宿主和真实显卡上看过。
