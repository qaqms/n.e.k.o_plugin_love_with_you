# 冒险关卡结构与地图设计提案

日期：2026-11-15。状态：**提案，未实现**。目的：回答“地图怎么设计、怎么让人愿意一直玩、越玩越爽”，并给出能分期落地的方案。确认后再拆成具体版本。

## 1. 现在的问题

- 一局是一张固定场地上的 20 分钟连续生存。空间从头到尾不变，敌人只是变多变硬。
- 局内唯一的决定是升级时三选一。没有“下一步去哪”的选择，也没有可期待的阶段目标，只有 6、12、18 分钟三个时间点。
- 奖励是平的：每分钟 6 金币，通关加 80。打得好和挂机活下来差别不大。
- 小首领和首领按时间出现在同一块地上，没有“进入首领房间”的仪式感。

## 2. 参考的四款游戏各自解决了什么

| 游戏 | 结构 | 值得借的点 |
| --- | --- | --- |
| Hades | 每个区域由十几个手工房间随机串起来，房间很短；清完后在 1–3 扇门里选，门上直接显示奖励类型；每个区域一个守关首领 | 短房间 + 可见奖励的选路，让“再打一间”有具体理由；房间手工设计、顺序随机 |
| Slay the Spire | 整张分叉路线图开局可见，节点分战斗、精英、事件、商店、休息、宝箱、首领；关键节点位置固定（首领前必有休息，前几层没有精英） | 路线图把“下一步是什么”变成“我要走哪条路”，每一步都是风险和收益的取舍 |
| Vampire Survivors | 单张大图上 15–30 分钟的生存，靠武器进化和持续解锁（角色、地图、模式）拉长寿命 | 一局内成长要快而且持续；局外要不断有小东西可解锁 |
| Brotato | 20 波、每波 20–90 秒，波间进商店花掉本波赚的钱，约 25 分钟一局 | 极短的战斗段 + 高频的构筑决定，数值变化马上能感受到 |

我们已有的东西更接近 Vampire Survivors：自动攻击、升级三选一、技能进化。缺的是另外三款共有的那一层——**把一局切成有名字的小段，段与段之间让玩家做选择**。

## 3. 核心方案：章节—区域—节点

一局 = 一章，仍然是 18–22 分钟，但切成三个区域加一场首领战，每个区域由若干节点组成。

```
出发营地
  └ 区域一 林缘        战斗 → 选路 → 战斗/事件 → 选路 → 精英守关
  └ 区域二 苔石遗迹    战斗 → 选路 → 商店/休整 → 战斗 → 选路 → 精英守关
  └ 区域三 荆棘深处    战斗 → 选路 → 事件/商店 → 战斗 → 休整
  └ 守望者圣所         最终首领
```

### 3.1 节点类型

| 节点 | 时长 | 内容 | 奖励 |
| --- | --- | --- | --- |
| 战斗 | 90–150 秒 | 小场地内的生存波次，带一个目标（见 3.3） | 门上预告的那一种奖励 |
| 精英守关 | 60–120 秒 | 区域末尾，一只小首领加杂兵 | 一次觉醒或融合 + 回复部分生命 |
| 事件 | 不战斗 | 两到三个选项的小抉择，有代价有收益 | 视选择而定 |
| 商店 | 不战斗 | 用本局拾取的“旅币”买技能强化、词条、回复 | 无 |
| 休整（营火） | 不战斗 | 回复生命，或与同行相处一次换取默契加成 | 二选一 |
| 首领 | 3–5 分钟 | 专属场地，分阶段 | 通关结算 |

### 3.2 选路

每清完一个节点，出口出现 2–3 条路，每条路上标着下一个节点的类型和奖励图标。规则借 Slay the Spire 的固定位：

- 每个区域的第一个节点必是战斗，最后一个必是精英守关。
- 首领前必有一个休整。
- 同一类非战斗节点不连续出现。
- 标着骷髅的战斗更难，奖励翻倍。

第一期不做整张路线图，只做“清完后选门”，实现量小很多，效果已经有大半。

### 3.3 战斗节点的目标（防枯燥的主要手段）

同样是打怪，换目标就换了打法：

- **坚守**：撑过倒计时。现有玩法，最基础。
- **清剿**：击败指定数量，打得快就结束得早。
- **守点**：场地中央有一盏灵灯，敌人会去打它，要在它周围作战。
- **追猎**：若干只带标记的精英散在场地里，逐个找出来击败。
- **突围**：场地边缘逐渐被荆棘封住，要一边打一边向出口移动。

每个区域有自己偏好的目标组合：林缘以坚守和清剿为主，遗迹加入守点，深处加入追猎和突围。

### 3.4 “越来越爽”的成长曲线

把现在散在 20 分钟里的强化集中成几个明确的爆点，并让怪物数量跟着涨：

| 时间 | 玩家状态 | 敌人 | 感受 |
| --- | --- | --- | --- |
| 0–5 分钟，区域一 | 2 个技能，刚成型 | 少而慢 | 学走位，认识技能 |
| 区域一守关后 | 第一次觉醒或融合 | — | 第一个爆点：技能外观和范围都变 |
| 5–12 分钟，区域二 | 3–4 个技能，开始有配合 | 数量翻倍，出现冲锋兽和咏者 | 构筑成型，需要处理预警 |
| 区域二守关后 | 第二次觉醒，同行协作解锁 | — | 第二个爆点 |
| 12–17 分钟，区域三 | 满配，词条叠起来 | 屏幕上最多，但单体脆 | 割草段：一局里最爽的三分钟 |
| 首领 | 满状态进场 | 一只大的 | 检验整局构筑 |

关键是区域三：数量拉满、单体变脆，让玩家明确感到“我比开局强了十倍”。现在的 20 分钟里没有这一段，后期只是怪越来越硬。

### 3.5 让人愿意再开一局的理由

按投入从小到大：

1. **每局路线不同**：节点顺序、目标、门后奖励随机，同一章能打出很多种过程。
2. **图鉴和小解锁**：首次遇到的事件、首次完成的目标、每种技能的首次觉醒，都记一笔并给少量金币。持续有小东西可拿。
3. **难度阶梯**：通关后解锁该章的“试炼”档，敌人更强、金币倍率更高，可叠加若干条自选限制。
4. **新章节**：每章换一个地貌和一套敌人、一个新机制。第二章在第一章通关后解锁。
5. **同行的关系**：这是这个游戏独有的。营火相处、事件里同行的反应、通关后的一句话，和插件本体的好感系统呼应，但不直接加减好感，避免把冒险变成刷好感的工具。

### 3.6 金币

现有的“每分钟 6 + 通关 80”改成和表现挂钩，总量保持在同一量级，避免局外商店失衡：

- 每清一个节点给固定金币，精英和首领更多。
- 带骷髅的节点额外加成。
- 中途失败按已清节点结算，不再按存活分钟。

具体数值在实现那一期按“一局通关约 200”反推。

## 4. 地图设计

### 4.1 尺寸与形态

现在的场地是 1800×1200 一整张。节点制下改成**每个节点一张小场地，约 1300×900**，一屏多一点。理由：

- 小场地里怪更密，同样的敌人数量压迫感更强，技能也更容易打到人。
- 每张图可以有明确的形状和主题，玩家记得住。
- 素材压力小：一张图只需要一块地表、一圈边界和五六种摆件。

首领场地单独设计，约 1500×1100，中间完全空旷。

### 4.2 每张图要有的四样东西

1. **形状**：不是矩形。圆形庭院、葫芦形林间道、被荆棘分成两半的洼地，形状本身决定走位。
2. **会影响战斗的地形**：两三处就够。挡弹的石柱、减速的泥沼或荆棘丛、可以打碎掉回复的陶罐、只能单向通过的窄口。
3. **地标**：一个一眼认得出的大物件——破马车、干涸的喷泉、发光的石碑。它同时是美术重点和方位参照。
4. **出口**：清场后亮起的 2–3 个出口，位置固定在边缘，和选路界面对应。

### 4.3 第一章“边境林地”的三个区域

| 区域 | 地貌 | 色调 | 地形机制 | 敌人 |
| --- | --- | --- | --- | --- |
| 林缘 | 草地、土路、木栅栏、大树 | 明亮的黄绿 | 巨石挡路，无负面地形 | 史莱姆、游灵、蛮兽 |
| 苔石遗迹 | 石板庭院、断柱、残墙、符文石 | 灰绿、冷光 | 石柱挡弹，符文石周期性发光增伤或减速 | 加入冲锋兽、咏者；守关为苔甲卫士 |
| 荆棘深处 | 暗色林地、巨根、荆棘墙、发光蘑菇 | 深青、紫、粉色点缀 | 荆棘丛减速并少量伤害，蘑菇踩爆后短暂照亮并击退 | 全部种类高密度；守关为荆棘咏者 |
| 守望者圣所 | 圆形石台、符文环、古树祭坛 | 青色光、落叶金 | 首领阶段性召唤根须封住部分场地 | 林地守望者 |

每个区域做 3 张战斗图，一局里随机用其中 2 张，加上精英图和非战斗图可以复用战斗图的素材。

### 4.4 素材做法

沿用角色的路线，AI 出图、脚本处理：

- **地表**：每个区域一张可平铺的地表纹理和两三种过渡贴片（土路、石板、苔藓）。
- **摆件**：树、石、柱、栅栏等，每种单独出透明底图，按显示尺寸切好；带碰撞的摆件在数据里标出形状。
- **场地布局**：用 JSON 描述每张图的轮廓、摆件位置、地形区和出口，不写死在代码里。新增一张图只需加一个文件。
- **概念图**：已为四个区域各出一张气氛图，用来定色调和元素，不直接进游戏。

## 5. 分期

每一期都能独立上线、独立试玩，不满意可以停在那一期。

| 期 | 内容 | 新素材 | 规则与存档 |
| --- | --- | --- | --- |
| A | 把一局切成节点：6 个战斗 + 2 个精英守关 + 首领，清完选门，门上显示奖励；两种目标（坚守、清剿）；沿用现有林地素材，做 2 张小场地 | 无 | 新规则版本 8，存档加当前节点与路线；旧版进行中的旅程按旧规则打完 |
| B | 非战斗节点：商店、休整、3–4 个事件；局内旅币；金币结算改为按节点 | 少量界面图标 | 规则 8 内扩展 |
| C | 三个区域的正式地图素材和地形机制；每区域 3 张图；首领专属场地 | 地表、摆件、首领场地 | 只换表现和布局数据 |
| D | 守点、追猎、突围三种目标；图鉴与小解锁；试炼难度 | 少量 | 局外存档加图鉴 |
| E | 第二章：新地貌、新敌人、新机制 | 全套 | 新章节数据 |

建议先做 A。它不依赖任何新美术，一两个版本就能验证“切段 + 选路”是不是真的更好玩；如果手感不对，损失最小。C 可以和 A、B 并行准备素材。

## 6. 风险

- **节奏被打断**：幸存者类游戏的爽感来自不停地打。节点之间的选路必须很快（三秒内能点完），非战斗节点一局不超过 3 个。
- **小场地太挤**：冲锋兽和范围预警在小图里更难躲，需要重新调数量和预警时间。
- **规则版本负担**：现在已经维护着 7 个规则版本的兼容。加第 8 个之前，建议先决定是否停止支持最老的几个版本。
- **工作量**：A 期主要是规则和存档改动，测试量不小；C 期素材量是角色的好几倍。
- **未经验证**：以上都是设计推断，没有真人试玩数据。每一期做完都需要你实际玩过再决定下一期。

## 7. 需要你决定的事

1. 是否接受“节点制”这个方向，还是想保留 20 分钟连续生存作为主模式、节点制作为另一个模式。
2. 一局时长保持 20 分钟左右，还是缩短到 12–15 分钟。
3. 概念图的色调和元素是否符合你想要的感觉。
4. 是否同意停止对规则 1–5 的进行中旅程的兼容。
5. 是否按 A → B → C 的顺序开始。
