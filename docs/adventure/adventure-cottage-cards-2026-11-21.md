# 0.9.27 小屋改版第 3 步（下）：统一的纸页卡片

对应 [改版方案](../plans/cottage-redesign-proposal-2026-11-20.md) 的界面方案 D2，接在 [0.9.26](adventure-cottage-house-2026-11-21.md) 之后。

## 改了什么

- **共用的纸页卡片**（`.paper-card`）：米白纸色、细纸纹、圆角和柔和阴影。
  - 标题用楷体一类的手写感字体，下面有一条虚线。
  - 按钮和下拉框统一成纸面样式。
  - 底部工具栏、返回按钮、礼物架的展示位按钮也换成同一套颜色。
- **相框和日历**改成「物件在一侧，卡片在另一侧」：
  - 宽屏：镜头把物件放在画面左边约三成的位置，卡片在右边滑出，一根细线从物件连到卡片。
  - 窄屏（< 575 px）：物件在画面上方，卡片是下方的一张纸片。
  - 位置计算在新模块 `static/cottage-card.mjs`。
  - 相框不再把画缩到上半部分来腾出说明区，日历也不再翻页，文字都在卡片里。
- **唱机、礼物架、双人杯**本来就是物件加旁边说明的布局，这次只换成纸页卡片样式。唱机的引线改为对准卡片标题。
- **便签本**保持文字直接写在本子纸页上，只把标题、角色选择和按钮换成同样的字体和纸面样式。
- **投影幕**也保持内容显示在幕布上。这一点和方案原文不同：原方案只把便签本列为例外，但投影幕放下来以后空白一片、旁边再弹卡片，看起来会很奇怪。投影幕的文字加大了。

## 测试

- 小屋浏览器测试 18 项全部通过，其中两项的断言按新布局改写：
  - 唱机引线现在终止在卡片边缘，并与卡片标题对齐。
  - 相框说明出现时，镜头已经停稳，画面保持不动，只有卡片在展开（原来断言的是画在缩小）。
- 在本机 GPU 上看过宽屏和 390 px 窄屏下六个物件的截图。

## 没做 / 未验证

- 楷体依赖系统字体：Windows、macOS 都有，其他系统会退回到宋体或衬线字体，没有内置字体文件。
- 双人杯卡片和礼物架的标签仍在物件正下方，没有改成侧边卡片，因为它们本来就是紧挨物件的小标签。
- 卡片内容翻页后高度变了，宽屏下卡片的垂直位置要等到下一次画面重绘才会重新居中。
- 没有在真实宿主上测试。
