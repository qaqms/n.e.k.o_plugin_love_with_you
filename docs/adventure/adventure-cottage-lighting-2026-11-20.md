# 小屋光照、镜头与画质

0.9.25 是[小屋重新设计方案](../plans/cottage-redesign-proposal-2026-11-20.md)的第 1 步，只改现有客厅的渲染和镜头，不改布局、物件和界面。

## 光照与材质

- 场景使用 Three.js 自带的 `RoomEnvironment` 作为环境光照。布料（沙发、靠垫、窗帘、薄毯、地毯）改为带绒面光泽的材质，杯子加釉面，木头降低粗糙度。
- 窗户成为光源：一盏聚光灯从屋外穿过窗口照进来，墙和窗框投下阴影。白天在地毯上留下窗格形状的光斑，黄昏的低角度橙光把窗格影子拉到屋子前部，夜里是偏蓝的月光。拉上窗帘会挡住光。
- 夜晚整体变暗。台灯打开后由灯泡、灯罩和桌面光池照亮周围，有柔和的光晕。
- 夜里推近物件时，环境光会随镜头提亮，方便阅读；沙发视角保持夜色。
- 背景按时段变化：白天浅绿、黄昏暖米色、夜晚深蓝，标题文字在夜晚改为浅色。色调映射从 ACES 改为 Neutral，保留原来的配色饱和度。

## 画质档位

| 档位 | 内容 |
| --- | --- |
| 低 | 直接渲染，只有主光阴影，窗外光不投影 |
| 中 | 多重采样抗锯齿、窗外光投影、光晕、暗角与分时段调色 |
| 高 | 中档加环境遮蔽（GTAO），阴影贴图更细 |

默认「自动」：软件渲染（如 SwiftShader）用低档，4 核及以下或窄屏用中档，其余用高档。自动模式下，如果镜头移动时连续出现明显掉帧，会自动降一档。偏好存在浏览器本地（`love_with_you:cottage:v1` 的 `quality` 字段），可以用页面地址参数 `quality=low|medium|high` 强制指定。选择档位的按钮留到第 3 步的工具栏改版时再加。

后期处理用到的 Three.js 示例模块由 `tools/build/vendor_three.mjs` 打包成 `static/engine/three-post.mjs`（three 0.180.0，MIT）。

## 镜头

- 正交相机改为透视相机。总览用 24° 视角，仍像微缩模型；推近物件时视角逐渐放宽到 38°（沙发 32°），出现真实的远近变化。
- 总览按透视投影后的房间四角重新居中和缩放，房间在画面中更大、更居中。
- 推近时的缩放改为按比例变化，从远到近速度均匀。时长和中途返回的路径保持不变。
- 物件界面（唱片封套、相框文字、便签纸页等）仍按目标平面的尺寸定位，与模型对齐。

## 兼容与验证

存档和浏览器本地偏好都可沿用，旧偏好没有 `quality` 字段时按自动处理。

- 小屋浏览器测试 17 项全部通过（SwiftShader，自动档为低档）。新增一项测试分别以低、中、高档渲染夜晚房间，检查画面内容和无报错，并确认高档画面与低档不同。
- 在本机 RTX 5070 Ti 上用高档逐个截图检查了白天、黄昏、夜晚（开灯和关灯）和沙发视角。
- 没有在真实宿主内试玩；没有在集成显卡或低端机器上测性能，自动降档的触发阈值也没有在真实掉帧场景下验证。
