# 小屋唱机特写

0.9.15 在小屋内增加了唱机专用交互。点击模型或唱机按钮时，镜头用约 660 毫秒推进到特写。镜头到位后，连接线从唱机前沿展开，所选角色的最近五张唱片封套依次出现。选中封套后才显示留存日期、收听进度与感想，唱机上的唱片也会转动。返回时恢复进入特写前的视角。窄屏将封套放在唱机下方，减少动态效果设置会跳过镜头和唱片动画。

唱机读取已有听歌回忆。关闭共同经历保存后，唱片与详情会清空。此版本兼容既有存档。相框沿用自身的回忆面板。

通过无头 Chromium 验证实际物件点击、展开顺序、视角恢复、角色隔离、窄屏触摸和关闭留存后的显示。预览使用示例数据，真实宿主联动尚未验证。
