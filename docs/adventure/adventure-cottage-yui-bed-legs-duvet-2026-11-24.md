# Yui 挪到床沿时腿不再乱动，上床躺平后伸手把被子拉回来（0.9.59，2026-11-24）

项目主人说：「问题一：上床的时候拉被子的动作对不太上；问题二：起床的时候挪下床位置时候的腿看起来怪怪的」。

## 问题二：挪到床沿时的腿

### 原因

0.9.58 挪到床沿那 1.2 秒里，宿主的起身动作（`getup`）一直从 1.0 秒放到 2.2 秒。这个动作本来是从地上站起来的：

- 1.0 秒左右是抱着膝盖坐着；
- 之后两膝分开、往下跪。

我们一边让她在床上转身、挪动，一边放着这段跪下去的动作，所以腿看起来很怪。截图见 `before-getup.png`。`clip-getup-0.8-1.5.png` 是这个动作 0.8–1.5 秒的侧面。

### 改法

- **`cottage-yui.mjs` 的 `perform`**：多了一种动作段 `for`。动作停在 `from` 那一帧，停若干秒，再接下一段。停了多久从 `acting.waited` 读。
- **`cottage-yui-life.mjs`**：
  - 起床改成：起身动作放到坐起来（`SAT_UP`，1.0 秒，抱着膝盖），然后停在这一帧 1.2 秒（`SCOOT_OUT`），这段时间里转身、两手撑床、分两下挪到床沿；
  - 新函数 `bedTime` 把停住的时间换算成原来的进度，所以转身、挪动、手撑、掀被子的时间都和 0.9.58 一样；
  - 到床沿后，照旧在 0.5 秒里换成坐在床边的姿势，这时腿才从床上放下去；
  - 半夜被叫醒、坐起来陪你的那条路径（停在 `PROPPED`）和之后接着起床，都改成同样的分段。
- **上床**是倒过来：坐在床边，换成抱膝坐在床沿（`SCOOT_IN`），两手撑着分两下挪进去，再躺下。

## 问题一：上床时拉被子

### 原因

0.9.58 上床时，被子是跟着起身动作倒放的进度合上的。实际是她还抱着膝盖坐着、没躺下，被子就在约 0.25 秒里自己合上了，没有手去拉。截图见 `before-into-bed.png`。

### 改法

- **先躺平，再拉被子**：上床的动作段变成「挪进去 → 躺下 → 停在仰躺那一帧 1.6 秒（`PULL`）→ 翻身睡」。被子只在 `PULL` 这 1.6 秒里从掀开慢慢合上。
- **伸右手拉**：
  - `cottage-duvet.mjs` 新函数 `edge(open, target)`：被子掀开 `open` 时，掀过去那一半的上角在哪（世界坐标）。掀开的被子堆在靠墙那侧，也就是她仰躺时的右手边。
  - `cottage-yui-life.mjs` 新读数 `pull`：开始时右手伸过去，被子拉过身体后松开。
  - `cottage-yui.mjs` 新函数 `pullHand`：用两段骨骼 IK 把右手放到被角上，随被角移动。够不着的时候不伸。
  - `cottage.mjs` 把被角的位置算好传给她。
- 坐起来陪你之后再躺下（`LIE_BACK`）那条路径，被子本来就盖着，不变。

## 没做的、没验证的

- **右手有没有真的抓在被角上，没有用探针量距离**。截图里卧室晚上光线暗，能看到右手往靠墙那侧伸，但看不清手和被角贴得多准。
- **被角离她远时够不着**：被子刚开始拉时，被角在靠墙的床边，约 0.9 米远，那时手只是往那边伸；被角拉近后手才跟上。没有做她侧过身去够的动作。
- **只用一只手拉**，没有换手，也没有做握住被子的手指。
- **抱膝坐着挪的时候，鞋踩在床垫上**（动作本身如此）。没有让她先把腿伸出床外。
- **到床沿后放下腿那 0.5 秒**是两个姿势之间的过渡，没有专门做的动作。
- **被叫醒坐起来、之后再起床**这条路径没单独拍。
- **减少动态效果时**的路径没改，也没跑那项约 23 分钟的浏览器测试。
- 0.9.55–0.9.59 都还没推送。
