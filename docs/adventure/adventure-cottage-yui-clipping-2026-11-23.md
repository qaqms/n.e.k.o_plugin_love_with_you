# Yui 穿模校正与就地互动（0.9.49，2026-11-23）

方案见 [Yui 的穿模、动作流畅度和过渡：方案](../plans/cottage-yui-motion-proposal-2026-11-23.md)。项目主人选了「一、穿模」和「三 A、就地互动」，并说明：坐下、起身、下床这些过渡本身仍是平移，后续还要解决。

## 改了什么

### 一、穿模

1. **按座位坐到坐面上**
   - `cottage-routine.mjs` 的每个座位记下坐面高度 `seat`，以及椅子前沿、靠背、靠背顶 `chair`。书桌位置往后挪了 3 厘米（-1.5 → -1.47）。
   - `cottage-yui-life.mjs` 新增 `seat` 读数：她坐在哪、坐下或起身进行到哪一步（0..1）。
   - `cottage-yui.mjs` 的 `sitOn` 在同一帧内把她的髋关节和大腿前半段放到坐面上。坐下时逐渐接管，起身时逐渐放开。
2. **手不进脸、不进坐面**
   - 新模块 `static/cottage-reach.mjs`：两段骨骼 IK，只转上臂和小臂，手肘保持原来的弯曲方向。
   - `clearHands` 检查手腕、食指尖和中指尖：
     - 进了头部球体就往外推；
     - 坐着时低于坐面就往上抬；
     - 推动量做平滑。
3. **裙摆和头发**
   - `cottage-springs.mjs` 新增：
     - 平面碰撞（可限定范围和作用的骨骼组）；
     - 碰撞体开关和整体偏移；
     - 向上推（坐着时腿上的裙摆往上推，不往下钻）；
     - 跟随大腿的角度上限。
   - 坐着时：
     - 打开臀部碰撞体，略偏后，挡住后片裙摆，不再露出皮肤；
     - 前片裙摆按朝向分配更多地跟着大腿，两条腿的份额归一，不会叠加转过头；
     - 臀部后方有坐面平面，裙摆铺在座位上；
     - 有靠背的座位加靠背平面，只挡双马尾，不挡裙摆。挡裙摆会把裙摆推进身体。
4. **打字的姿势**：`CLIP_FIX` 把上身、脖子、头抬起一点，能看到她的脸。

### 三 A、就地互动

`life.interrupt` 现在返回她怎么接这次点击，`yui.react(how)` 据此反应：

| 情况 | 现在 | 以前 |
| --- | --- | --- |
| 坐着，你在她面前（和她朝向的夹角 < 约 110°） | 留在座位上，脸和视线转向你，近景从她正面偏向你那一侧（最多 0.6 弧度）。沙发和长椅上会播「坐着开心地大笑」的 1.0–3.3 秒，之后接回坐姿 | 先滑出座位站起来 |
| 坐着，你在她背后（书桌朝墙） | 照旧站起来 | 同左 |
| 睡着时被叫醒 | 嘟囔、翻身，然后在床上撑起来坐着，看你。起身动作停在 0.7 秒那一刻（往后撑着、脸朝上；1 秒时头是低着的）。你离开后：还在睡觉时间就躺回去翻身睡；到了起床时间就从坐着接着起身下床 | 整套下床、站到床边 |
| 站着忙事（看平板、打哈欠、走在路上） | 先播「惊讶地向后缩起身体」，0.9 秒后才转向你 | 直接转过来 |
| 站着空闲 | 原来的手势（V 手势、点赞） | 同左 |

配套修正：

- **近景对准胸口的实际位置**：`yui.chest` 站着时仍是根部上方 1.2 米；坐着或在床上时跟着胸口骨骼走，有平滑。在床上坐着时镜头略往下看（俯角 0.22），越过被子下拱起的膝盖。
- **视线从头部的实际位置算起**（坐着、在床上时）。原来一律按站着的头高算，坐着时会把和她脸一样高的你算成在下方，于是低头。
- **视线移开时看的地方**：原来固定从一楼客厅的几样东西里挑。在楼上时，她会隔着地板往下看，看起来像低头打瞌睡。现在只挑同一层 4 米内的东西；没有就看前方左右、和眼睛一样高的地方。

  - 手移到指定位置，手臂长度不变；
  - 手肘弯曲平面不变；
  - 够不到时伸到最远，位移为 0 时什么都不动。

## 没做的、没验证的

- **沙发上翘腿时前片裙摆翻起**，露出深色内侧。跟随角度上限没能解决。可以用的市面做法见下一节。
- **书桌**坐姿从一侧看，大腿和裙摆之间还有一小块缝。
- **尾巴**不和座位碰撞，坐着时会穿过坐面。
- **过渡本身仍是平移**：坐下、起身（背对你时、她按作息走动时）、下床（到起床时间时）还是原来的「滑过去 + 交叉淡化」。这是项目主人说的后续工作。
- **「Yui keeps her day … a click wakes her」没跑**。这一项在减少动态效果下点醒她，整套里约 23 分钟。改动没有碰这条路径（不动画时被叫醒仍是直接站到床边），但没有实测。
- 被叫醒后坐在床上的近景只在一个窗口尺寸（1100×760）看过，窄屏没看。
- 「坐着笑」只用于坐姿 `sit`。书桌的打字姿势如果从正面点（实际上书桌朝墙，很难从正面点），只转头，不笑。
- **高刷新率下弹簧骨骼是否一顿一顿**（方案里的第 5 条）没量。

## 裙子穿模：市面上的做法

项目主人问：如果裙子穿模不好解决，市面上有没有现成的好技术可以用。查到的主要有四类：

1. **大碰撞体 + 坐姿专用碰撞体**（VRChat、VRM 圈子的常见做法）。工具会自动给大腿、胯部、膝盖、后腰生成较大的胶囊，专门应对坐下和走路时的裙子穿模。例如：
   - [VRMSkirtTool](https://booth.pm/ja/items/4649508)
   - [スカート貫通ガード](https://booth.pm/ja/items/8660959)

   我们 0.9.49 做的臀部碰撞体、向上推的腿部碰撞体就是这一类。它的上限是：碰撞体只能把骨骼点推开，挡不住裙片本身的面。
2. **「穿透约束」/「背面约束」**。Unity 上常用的 MagicaCloth 有一个 Penetration 设置：每个布料点相对身体表面只许待在外侧一定范围内，算是最后一道防线，不靠碰撞体一个个去挡（[MagicaCloth 讨论帖](https://discussions.unity.com/t/released-magica-cloth/773425?page=49)）。我们的弹簧骨骼可以照这个思路加：裙摆每个关节相对大腿和臀部，只允许在外侧一个角度范围内活动。这是纯代码，不要新素材。
3. **真正的布料模拟（XPBD）**：
   - 网页上有 WebGPU 的蒙皮网格布料，比如 [three-simplecloth](https://github.kxpsado.workers.dev/bandinopla/three-simplecloth)；
   - 有 [XPBD 裙子在 GPU 上跑的项目](https://sueraywang.github.io/project/xpbdmmd)；
   - 也有 WebGL 的布料实现思路（[PlayCanvas 博客](https://blog.playcanvas.com/implementing-cloth-simulation-in-webgl)）。

   效果最好，但小屋目前是 WebGL，加上画质已经压在中等档 45–52 毫秒一帧，现在上整块布料模拟太重，不建议。
4. **离线烘焙**。游戏里坐下时裙子不穿模，很多是把坐姿时的裙子做成固定形状，不实时模拟。《模拟人生》、《饥荒联机版》这类游戏的裙子坐姿问题，社区和官方也都是按姿势单独处理：
   - [Sims 4 Studio 帖子](https://sims4studio.com/thread/34735/skirt-legs-clipping-problem-solved)
   - [饥荒联机版问题单](https://forums.kleientertainment.com/klei-bug-tracker/dont-starve-together/skirt-position-on-chairs-r50349/)

   这一条是我从搜索结果归纳的，不是哪个工具的现成功能。现在主人装了 Blender，可以这样做：
   - 每个坐姿用 Blender 的布料模拟让裙子自然垂落在腿和座位上；
   - 把结果记成裙摆骨骼的一组固定转角；
   - 坐稳时把弹簧骨骼淡出、换成这组转角，起身时再淡回去。

**建议**：

- 坐姿用第 4 条（Blender 烘焙），翘腿翻裙、书桌缝隙这类问题都能一次解决，运行时几乎不花性能；
- 走路和站着用第 2 条（穿透约束）补强现在的弹簧骨骼；
- 第 3 条等以后小屋换 WebGPU 时再考虑。

这两件都是新方向，按规矩先请主人选。
