# Yui 的裙子：Blender 烘焙坐姿 + 走路时的大碰撞体与穿透约束（0.9.50，2026-11-23）

0.9.49 的文档里比较了几种市面做法（见 [0.9.49](adventure-cottage-yui-clipping-2026-11-23.md) 最后一节）。项目主人选了推荐的组合：

- 坐姿用 Blender 布料模拟烘焙；
- 走路和站着用穿透约束补强弹簧骨骼。

## 坐姿：Blender 烘焙

### 做法

1. **导出**（`tools/assets/skirt_bake_export.mjs`，用 Playwright 跑小屋自己的代码）：
   - 让 Yui 按游戏里的方式坐下，包括坐面校准和手的校正；
   - 每秒 30 帧，记录她双腿和鞋的网格（约 5600 个点）和骨盆矩阵；
   - 记录一张「裙布」：沿 8 条裙摆骨骼链，每两条链之间再插 3 列，每段骨骼之间再插 2 行，顶上一行就是腰。
2. **布料模拟**（`tools/assets/skirt_bake.py`，用 Blender 5.3 后台运行）：
   - 腿是碰撞体，用 Mesh Cache 修改器按帧动起来；座位是一个碰撞方块；裙布是布料，腰那一行钉住；
   - 裙布物体按骨盆矩阵逐帧打关键帧，腰跟着她动，其余部分由布料模拟决定；
   - 开始时她已坐好，裙布像伞一样从腰部平摊开，在腿和座位上方。静止 2.5 秒让它落到腿上，再播动作；
   - 循环动作（坐、打字）跑两遍，取第二遍；
   - 把裙布在骨骼关节处的点按骨盆坐标系记下来，每秒 15 帧。
3. **结果**：`static/models/skirt-seated.json`，约 230 KB，包含三段：
   - `sit`：坐着，沙发、长椅、餐桌用；
   - `type`：打字，书桌用；
   - `sit-laugh`：被点时坐着笑的那一段。

   每段按动作时间存 24 个点（3 层 × 8 条链）。
4. **运行时**（`cottage-yui.mjs` 的 `drapeSkirt`）：
   - 坐稳（座位权重超过 0.6 起逐渐生效）且当前动作有烘焙数据时，按动作当前时间取出这一帧的裙摆位置，换算到她骨骼的当前位置；
   - 再交给 `cottage-springs.mjs` 的新接口 `setTargets`：弹簧骨骼的尾端按权重拉到这些位置，长度不变；
   - 两段动作交叉淡化时（坐着 → 坐着笑），两份烘焙也跟着交叉；
   - 坐下、起身或换到没有烘焙的动作时，权重平滑地淡入淡出，弹簧骨骼接回去；
   - 数据加载失败就只用弹簧骨骼，和 0.9.49 一样。

### 过程中踩过的坑

- **从站姿过渡到坐姿再模拟**：大腿抬起时把裙布兜在下面，裙子皱成一团夹在两腿之间。改为一开始就坐好、裙布平摊在上方。
- **骨盆骨骼的「上」不是房间的「上」**：第一次平摊时裙布是往上翘的。改为在世界坐标里平摊。
- **布料下面接 Mesh Cache**：Blender 的布料会用错静止形状，第二帧就缩成一团。改为给裙布物体打关键帧，跟着骨盆走。
- **手作为碰撞体**：笑的时候手从腿上抬起，会靠摩擦把裙子拽上去。游戏里手本来就盖在裙子上面，所以碰撞体只留腿和鞋。

## 走路和站着

1. **穿透约束**（`cottage-springs.mjs` 的 `backstop`，思路来自 MagicaCloth 的 Penetration）：
   - 每个裙摆关节往身体内侧摆的角度，最多比动画（含跟随大腿）给的方向多 0.3 弧度（`SKIRT_BACKSTOP`）；
   - 内侧指向骨盆的竖轴。它是最后一道防线，防的是弹簧甩过头往里钻。
2. **加大大腿碰撞体**（VRChat 圈常用的做法）：大腿胶囊半径从 0.066 加大到 0.09（`THIGH_RADIUS`）。
   - 原因：两条裙摆链之间，裙子表面是直线连过去的。腿往前迈时，大腿会从两条链中间穿出来，前片中间出现一道竖缝，露出腿。
   - 对比过：只加穿透约束这道缝还在，是加大碰撞体后消失的。

## 怎么重新烘焙

改了坐姿动作、座位高度或裙摆骨骼之后，需要重新烘焙：

```
cd tools
node assets/skirt_bake_export.mjs <临时目录>
cd ..
D:/blender.exe -b --factory-startup -P tools/assets/skirt_bake.py -- <临时目录> static/models/skirt-seated.json
```

整套约 6 分钟（打字那段最长）。可选的环境变量：

- `SKIRT_BAKE_RENDER=<目录>`：每隔一段渲染正面、侧面图，用来检查；
- `SKIRT_BAKE_FRAMES=2,40,…`：再指定额外要渲染的帧。

## 没做的、没验证的

- **烘焙按一个通用座位做**（坐面前沿在她前方 0.2 米），沙发、长椅、餐桌共用一份。长椅前沿实际只有 0.11 米，裙摆垂下来的位置和真实座位略有出入，截图里看不出问题，但没逐个座位烘焙。
- **坐下和起身的过程中**是弹簧骨骼和烘焙结果在交接，只看过坐稳后的样子，没逐帧看交接过程。
- **大腿碰撞体加大后**，站着时裙摆会比以前略往外撑一点。侧面截图看着正常，没在所有动作上检查。
- **尾巴仍不和座位碰撞。**
- **过渡本身仍是平移**（坐下、起身、下床），这是后续工作。
- **烘焙用的是骨骼链上的一张裙布**，不是裙子的真实网格，褶子的细节仍由原来的蒙皮决定。
