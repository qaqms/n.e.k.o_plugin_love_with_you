# Yui 走楼梯：一级一级踩着台阶上下楼（0.9.55，2026-11-24）

0.9.54 之后列下一步候选时，我推荐先做「真的走楼梯」，项目主人说「进行做真实的走楼梯」。

## 以前

她走到楼梯口（厨房里，楼梯脚下），往前走 0.3 米，同时在 0.45 秒里淡出；然后直接出现在楼梯顶（书房），再淡入。下楼反过来。她一天上下楼好几次，这在总览和厨房视角里很显眼。

## 楼梯本身

楼梯的数据在 `cottage-layout.mjs` 的 `STAIRS`，`cottage-house.mjs` 按它画出来：

- 共 14 级，从厨房前面（z = 1）爬到后墙（z = −2.55），最上一级和二楼地面一样高（3.52 米）；
- 每级高约 25 厘米、深约 25 厘米，坡度接近 45°，比一般住宅楼梯陡；
- 二楼地板在楼梯上方留了开口，开口靠房间的一侧有栏杆，栏杆从开口后端往前 0.6 米处开始。所以从最上一级下来，只能往左走到后墙和栏杆之间那 0.6 米宽的地方。

## 改了什么

### 新模块 `static/cottage-stairs.mjs`（纯函数）

用「走了几级」（`u`）描述她在楼梯上的进度。第 0 到 13 级是台阶，−1、−2…是楼梯前面的地面。

- `climbFeet(u)`：两只脚各在哪。
  - 两脚交替，每只脚隔一级踩（左脚踩单数级，右脚踩双数级），一般人上楼都是这样走。
  - 每只脚有 45% 的时间在空中，所以总有一只脚踩着。
  - 抬起的脚先往上抬，再往前越过中间那级的边缘，落到下一级；下楼是同一条路线倒过来：先往前越过边缘，再往下落。
  - 脚踝落在每级中间偏后 5 厘米处（`FOOT_BACK`）。
- `climbBody(u)`：她站的位置。在两脚中间，高度是两只脚所在台阶的平均。两脚在不同台阶上时，再往下沉 15 厘米（`CLIMB.sink`），让后面那条腿够得着下面一级。
- `climbPhase(u)`：走路动作该放到循环的哪一刻，让手臂和步子对上。
  - 在页面里量过：走路动作中左脚在循环的 0.72 到 1.17 之间抬起，右脚在 0.22 到 0.67 之间，各占 45%。所以「脚在空中的时间」也定为 45%。
- `CLIMB`：
  - 上楼每秒 1.7 级，下楼每秒 1.9 级，从站着起步，快到头时减速；
  - 楼梯顶下来的落脚点 `landing` 在栏杆前面。

### `cottage-yui-life.mjs`：新的 `climbStairs`

- **上楼**：
  1. 从楼梯脚下的路线点走到楼梯前，面朝楼梯；
  2. 一级一级爬到最上一级；
  3. 往左走到 `landing`，进书房；
  4. 接着按原来的路线走（比如去书桌）。
- **下楼**：
  1. 从书房走到 `landing`，再走上最上一级；
  2. 转身面朝下，一级一级走下去；
  3. 走到楼梯脚下的路线点，继续去要去的地方。
- **上楼时身体往前倾一点**，下楼几乎不倾（`CLIMB_BEND`）。快到楼梯两头时，倾斜慢慢收回去。
- 新读数 `climb`：只在爬楼梯时有值，告诉 `cottage-yui.mjs` 脚放在哪，以及走路动作的相位。
- **看楼下房间时**（厨房、客厅等），二楼整层会被抬走，她站在二楼时也跟着被抬起：
  - 楼梯不属于二楼，在楼梯上时不跟着抬（`onStairs`）；
  - 从最上一级走进书房时，为了不让她一下子跳上抬走的二楼，在楼梯顶淡出，在书房里淡入；下楼时反过来，在书房淡出，在最上一级淡入后往下走。
  - 看二楼和总览时，二楼没被抬走，她直接从开口走上来，不淡出。
- **旧的淡出淡入**只剩上床（缺少动作文件时的后备路径）在用。原来淡出时往楼梯里走 0.3 米的那段代码删掉了。

### `cottage-yui.mjs`

- `update` 多了参数 `climb`（`cottage.mjs` 从 `life.climb` 传进来）。
- **相位跟着步子**：
  - 爬楼梯时，走路动作的播放时间由 `climb.phase` 决定，不再按速度推进；
  - 刚开始爬时，动作当时所在的位置和应该在的位置不一样，差值在约半秒里慢慢收掉（`climbLock`），不会一下子跳过去。
- **脚放到台阶上**（`climbFeet`）：
  - 用 0.9.49 的两段骨骼 IK 把脚踝放到 `climbFeet` 给的位置，左右方向仍按动作本身的间距；
  - 脚掌保持动作里原来的朝向，不随小腿的弯曲翻转；
  - 开始爬时约 0.15 秒内渐入，走下楼梯后约 0.1 秒内渐出；
  - 爬楼梯时不再用 0.9.53 平地上的锁脚（`walkFeet`）。
- `cottage-reach.mjs` 的 `reach` 多了一个可选参数 `bend`：膝盖应该往哪个方向弯。腿几乎伸直或稍微反弯时，靠骨骼自己的弯曲平面判断不了方向，就用这个参数，保证膝盖往前弯。手臂的用法不变。

## 量出来的结果

在页面里用探针，让她按游戏里的速度从楼梯底爬到顶、再从顶走到底，逐帧检查：

| 检查 | 上楼 | 下楼 |
| --- | --- | --- |
| 脚踝离该在的位置超过 2 厘米的帧 | 0 / 740 | 0 / 740 |
| 脚尖最多插进台阶（厘米） | 2.9 | 3.0 |
| 膝盖往后弯的帧 | 0 | 0 |

- 第一次量时，脚快落下的那一刻脚尖插进上一级的立面约 20 厘米。原因是走路动作落脚时脚尖朝前上翘。把落脚点往后挪 5 厘米后，降到 3 厘米以内，相当于脚尖碰到台阶。
- 0.9.53 那套平地锁脚在楼梯上没有用。

  - 楼梯顶和二楼地面一样高；
  - 开始和结束时两只脚在同一级上；

## 没做的、没验证的

- **楼梯脚下会停一下**：她走到楼梯前先停住、对准方向，再起步爬，没有边走边拐上去。下楼走到最上一级后也会停一下，再转身往下走（转身时脚没有踩小碎步）。
- **走路动作是平地上的**：手臂、上身的动作都是平地走路的，只有腿和脚按楼梯重新摆。上楼时身体前倾一点，但没有扶栏杆。
- **后脚**：腿伸到最长时，后脚跟可能离开台阶一点（像蹬地），没单独量。
- **看楼下房间时**，在楼梯顶仍然淡出淡入。这是因为二楼整层被抬走了，没有地方让她走上去。
- **「看看她」镜头**在她爬楼梯时没专门调过。爬到一半房间从厨房变成书房时，镜头会像以前换房间一样退出近景。
- **楼梯上被点**：她会先走完楼梯，再停下来陪你（和以前在楼梯口时一样），没专门测过。
- **减少动态效果时**她不走路，直接出现在该在的地方，这条路径没改，也没跑那项约 23 分钟的浏览器测试。
- 0.9.55 还没推送。
