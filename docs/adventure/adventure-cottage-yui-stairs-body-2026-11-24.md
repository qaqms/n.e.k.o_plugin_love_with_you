# Yui 走楼梯时身体也跟着动：逐级起伏、前倾、看台阶、扶栏杆（0.9.57，2026-11-24）

项目主人说，0.9.55 的走楼梯「单纯是腿在走，身体没有协同，看起来很奇怪」。

## 原因

0.9.55 只重新摆了腿和脚，上身用的仍是平地走路的动作：

- 身体匀速往上滑；
- 上身几乎是直的（只前倾约 6°）；
- 眼睛看前方；
- 两只手照平地走路那样大幅摆动。

## 改了什么

### 身体一级一级上去（`cottage-stairs.mjs`）

- `climbBody(u, up)` 多了方向参数。
- **上楼**：每踩上一级，在蹬直那条腿的那一段里升得快，两步之间几乎不升。
  - 具体是：一级的上升里 60% 按这个节奏，40% 仍匀速（`BY_STEP.up`）。
  - 在楼梯两头逐渐收回成匀速，所以起点和终点高度不变，仍正好在地面和最上一级上。
- **下楼**：大部分时间都在往下放身体，所以只稍微按步子分段（`BY_STEP.down`）。
- 新函数 `railAt(z)`：栏杆上某处的位置。栏杆从第一级上方到倒数第二级上方，离台阶 0.9 米高，在楼梯靠厨房的一侧（和 `cottage-house.mjs` 画的一致）。

### 上身前倾、看台阶（`cottage-yui-life.mjs`）

- **上楼前倾**：从约 6° 加大到约 9°。每次蹬腿时再多倾约 6°（`CLIMB_BEND`），快到楼梯两头时收回来。
- **下楼**：只微微前倾（约 3°）。
- **视线**（`CLIMB_LOOK`）：
  - 上楼看前上方约 1 米处的台阶；
  - 下楼低头看脚前约 1 米、低于脚 0.35 米的地方。
- 读数 `climb` 多了：
  - `up`（方向）；
  - `rail`（手该扶的位置）：上楼时在身前 0.18 米；下楼时在身体侧边，因为下楼时栏杆往前是往下斜的，放前面就够不着了。

### 扶栏杆、另一只手摆幅变小（`cottage-yui.mjs`）

- 新函数 `climbArm`：用两段骨骼 IK，让靠栏杆那一侧的手扶在栏杆上，手腕在栏杆上方 5 厘米，随她往前滑。
  - 上楼是左手，下楼是右手（栏杆在厨房那一侧）。
  - 开始上下楼时约 0.2 秒扶上去，到栏杆两头或够不着时松开。
- 另一只手的摆幅降为平地的 55%（`CLIMB_ARM_SWING`）。

## 量出来的结果

在页面里用探针，按游戏里的速度从底爬到顶、再从顶走到底，逐帧检查：

| 检查 | 上楼 | 下楼 |
| --- | --- | --- |
| 扶栏杆的手离该在的位置 | 0–0.4 厘米 | 0–1 厘米 |
| 脚踝离该在的位置超过 2 厘米的帧 | 0 / 740 | 0 / 740 |
| 脚尖最多插进台阶 | 3 厘米 | 3 厘米 |

- 第一版下楼时，扶手位置也放在身前 0.18 米，右手差 17–23 厘米够不着，所以改到身侧。
- 规则测试里检查下楼时，楼梯顶的身体高度差了 2.5 毫米，所以加了「两头收回成匀速」。

## 没做的、没验证的

- **手扶在栏杆上的手型**还是走路动作里的手型，没有做握住栏杆的手指。手腕的朝向也没专门调。
- **扶栏杆那只胳膊**：肩膀到栏杆只有约 35 厘米，胳膊弯得比较多，从某些角度可能看着别扭。没从正面、侧面逐一截图。
- **骨盆、上身左右重心转移**仍用平地走路动作里原有的，没有按楼梯加大。
- **上楼开始前和到顶后**，脚下停一下的问题（0.9.55 记下的）这次没改。
- 0.9.55–0.9.57 都还没推送。
