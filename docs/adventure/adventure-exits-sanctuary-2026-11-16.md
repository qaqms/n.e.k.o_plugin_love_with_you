# 旅程 C 期第三步：走出口选路与首领圣所（开发步骤 0.9.6，随发布版本 0.9.2 推出，战斗规则 17，存档版本 18）

2026-11-16。按项目主人确认的方案完成旅程 C 期。出口和选门面板两种方式都保留。

## 玩法

### 走出口选路

- 规则 17 起，打完一段后不再自动弹出选门面板。场地边缘会亮起出口，最多四个，依次在北、东、西、南，每个出口上方写着林地名、目标和奖励。普通门是金色，险路是红色，停靠点是蓝色。
- 走进出口就进入那条路。这时游戏照常运行，但不会刷怪，可以先把掉在地上的东西捡完。
- 按暂停会看到和以前一样的选门面板，可以直接点选，也可以点「回到场地 · 走向出口」继续走路。
- 走进停靠点的出口，会照常打开篝火、行商或奇遇面板。处理完回到场地，停靠点出口消失，其他出口还在。
- 一段打完时会自动存一次档。读档时如果停在选路阶段，出口会重新亮起。

### 首领圣所

- 首领进入第二阶段后，石台上的立石亮起绿光。目前只是提示，没有额外效果。
- 第三阶段「根须封场」：石台外面的地面被根须覆盖并压暗，站在外面每 0.5 秒掉 3 点生命，最多扣到剩 1 点。石台范围是以 (900, 600) 为中心、横向半径 470、纵向半径 320 的椭圆。

## 实现

- `static/journey.mjs`：新增 `walking`、`roaming`、`exitPoints`、`drawExits`、`paintExits`、`walk`。选路阶段由 `update` 画出口，并检测玩家是否走进 50 以内。`openDoors` 在走路模式下不再自动打开面板；停靠点处理完回到场地。
- `adventure.mjs`：`play()` 在走路模式的选路阶段正常运行；读档后会重新画出出口。
- `static/hazards.mjs` 新增 `sanctuary`，数据在 `terrain-rules.mjs` 的 `HAZARDS.sanctuary`。
- 快照格式不变。规则升到 17，因为选路流程变了：规则 16 及更早的旅程仍然弹出面板，圣所也没有根须。存档版本升到 18。
