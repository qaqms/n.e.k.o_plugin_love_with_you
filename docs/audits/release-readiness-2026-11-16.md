# 发布前检查（0.9.0）

本次检查范围为插件工作目录、远程 `main` 对应的全部本地 Git 历史、当前导入包，以及本机由游戏浏览器测试生成的临时存档。宿主代码、已安装插件和实际玩家存档不在清理范围内。没有发布标签、创建 Release 或向市场提交。

## 敏感信息

初次扫描覆盖 350 个已跟踪文件、15 次提交及 638 个去重的历史文件内容，未命中配置的密钥规则，也未发现已提交的实际存档、私有配置、数据库或日志。新增的扫描工具还检查 Git 未忽略的新文件，最终扫描以本地报告为准。

检查规则包含常见 API 令牌、GitHub/GitLab/npm 令牌、AWS 访问标识、Google API 密钥、Slack/Telegram 令牌、JWT、私钥头、含凭据 URL 和直接赋值的高熵配置。报告只包含规则、路径、行号和不可逆短指纹，不写出匹配值。规则扫描不能证明没有任何自定义、编码或低熵秘密。

没有重写 Git 历史。项目历史包含旧开发目录路径、测试角色名、公开的 GitHub noreply 作者邮箱与素材来源记录，这些没有被当作用户聊天或密钥删除。

## 发布范围与无用文件

`pyproject.toml` 改为明确的发布文件范围：后端、界面、游戏、素材、多语言、项目元数据、README、示例配置、使用指南和礼物说明。开发设计、审计、方案、测试、工具、AGENTS、lint 配置、Git 忽略配置和本地归档不进入新导入包，仍在源码仓库中供后续维护。

同时排除环境文件、私有配置、日志、数据库、私钥、备份、`data/`、`saves/` 和 `custom_portraits/`，并扩展 Git 忽略规则。`static/*.json` 的技能、旅程、精通和遭遇目录属于运行数据，必须保留；图库清单和对应图片仍在使用，不能只因它们是 JSON 或图片就删除。

面板构建补充同一宿主源码中的 Apache 2.0 LICENSE 和 NOTICE，随游戏引擎已有许可一并发布。Lucide 通知保留在图标源码和生成文件中。

## 存档清理

源码和导入包中没有真实的 `state.json`、`adventure.json`、`appearance.json`、`portraits.json` 或自定义图库存档。SDK 数据目录的真实好感、金币、纪念日、经历和游戏进度均未清除。

清理脚本只接受系统临时目录下 `neko-adventure-test-` 加六位随机字符的目录，跳过正在使用、含链接、子目录或不认识文件的目标。清理前把已识别的合成测试存档压入本地归档，操作前再次验证每个绝对路径。首次清单为 1036 个目录、1034 个文件、3650345 字节；最终执行结果记录在 `archive/reviews/release-audit-20261116/test-save-cleanup.json`。

测试工具现已在正常结束和初始化失败时停止测试服务器并清理自己创建的目录，避免重复留下测试存档。开发备份和旧导入包按前次约定继续保留，不把它们当作玩家存档删除。

根目录的 `.ruff_cache` 与空 `.benchmarks` 已移入本地 `archive/reviews/release-audit-20261116/local-caches/`，保留恢复能力，不进入仓库或导入包。

## 验证结果

- 宿主 SDK 的 `precheck` 通过 lint、sync、release-check 三阶段。检查对象为当前工作区受 Git 忽略规则约束的 357 个源码文件的临时副本，避免将本地开发依赖混入源码检查；宿主未修改。完整输出在 `archive/reviews/release-audit-20261116/market-precheck.json`。
- 1156 项 Python 测试、87 项 Node 纯规则测试和 8 项定向浏览器测试通过。浏览器覆盖起手选择、移动与暂停、失焦、死亡、读档选择、控制权接管，以及桌面、390px 窄屏和焦点报告异常下的嵌套导航。没有重跑约 20 分钟的完整战斗浏览器套件，也没有代替项目主人操作宿主验收。
- 故意令浏览器启动失败，确认预览服务器退出且测试数据清理；定向测试后 `neko-adventure-test-*` 临时目录为 0。UI 类型检查覆盖 13 个文件，多语言检查覆盖 8 种语言，保留 6 项原有翻译未完成提示。
- 实际 SDK 打包匹配规则验证了 19 个私有或开发路径被排除、13 个运行路径被保留。导入包包含 251 个源码文件及生成的元数据，共 252 个载荷文件；CRC、载荷哈希、源码逐字节比对、23 个后端模块导入和合成旧存档迁移验证通过。
- 最终敏感信息扫描覆盖 357 个当前源码文件、15 次提交、638 个历史文件内容及导入包的 252 个载荷文件，未命中规则。报告在 `archive/reviews/release-audit-20261116/secrets-and-package.json`。

预检仍有两项警告：临时导出的源码不含 Git 元数据，以及当前宿主不识别 `plugin.toml` 的 `[plugin].models` 字段。预检报告标记 `market_check_mode=legacy`；本次结果不代表远程市场审核、版本标签或提交检查已经通过。插件版本仍为 0.9.0，战斗规则 12、存档版本 13 不变。

复查命令见 `tools/README.md`。扫描报告与测试存档备份仅留在忽略的本地归档中；仓库中的本文记录检查范围、结论和限制。
