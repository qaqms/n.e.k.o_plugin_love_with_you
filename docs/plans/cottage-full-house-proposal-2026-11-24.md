# 方案：小屋补成完整的房子，用透视模式看 Yui（2026-11-24，待主人定）

项目主人说：想把现在「一面有墙、一面没墙」的房子改成完整的房子，补上墙、补上缺的房间和物品，改用透视模式看人物。透视模式选了「两种都要」：墙自动切矮，再加上被挡住时显示她的轮廓。补房间选了「补前墙，再往前加一排房间」。

按 AGENTS.md，大方向先给方案，主人定了再做。

## 1. 现在是什么样

- **房子是娃娃屋**：x 从 −3.25 到 7（门廊到 10），z 从 −2.65 到 2.65。正面（+z）整面敞开，没有墙。
  - 一楼：客厅、厨房，加上门廊小院（室外）；
  - 二楼：卧室、阁楼书房。
- **镜头只能在正面右前方转**：左右 0.13–1.24 弧度（约 64°），上下也有限。所以看不到房子背面和侧面。
- **挡住镜头的侧墙会淡出**（`fadeWalls`）。看一楼房间时，二楼整层往上抬走。
- **「看看她」近景**会钻进墙里、被家具挡住，这是待打磨清单里的头一条（`cottage-yui-polish-backlog-2026-11-24.md`）。

## 2. 要做的四件事

### A. 补墙，往前加一排房间

- **房子往前扩**：在 z = 2.65 处补上原来的前墙（变成内墙，开门），再往前加一排约 3 米深的房间，新的前墙在 z ≈ 5.7。
- **建议的新房间**（等你定）：
  - 一楼：
    - **玄关**：大门移到这里，放鞋柜、挂衣钩、伞架；
    - **浴室/洗手间**：洗手台、浴缸；
    - **洗衣/储物间**：洗衣机、晾衣架、杂物架。
  - 二楼：
    - **衣帽间/梳妆台**：衣柜、镜子；
    - **小阳台**（半室外）：盆栽、晾衣绳、看外景；
    - 也可以换成**客房**或**画室**。
- **外景跟着动**：前院的篱笆、花坛、小池塘要往前挪，留出新房子的位置（`cottage-grounds.mjs`）。
- **门廊小院**留在原处（x 7–10）。新的一排是否一直延伸到门廊前面，由你定。

### B. 墙自动切矮（像模拟人生）

- 四面都有墙。镜头转到哪边，挡在镜头和房间之间的墙就**降成约 0.4 米高的矮墙**；不挡的墙照常立着。
  - 降墙不是变透明：墙被切开的那一截顶上画一条深色的切面，一看就知道是切开的墙。门窗跟着一起切开。
  - 实现：每面墙的材质加一个水平裁切面（three.js 的 `clippingPlanes`），切的高度平滑变化，切面顶上补一条盖板。
- **三档墙模式**，工具栏可切（模拟人生也是这样）：
  - 墙全立；
  - 自动切（默认）；
  - 墙全降。
- **镜头可以绕房子 360° 转**，不再只能看正面。各房间的视角保留，作为转到这个房间的起点。
- **二楼**：看一楼时，二楼照现在这样整层抬走（或改成直接隐藏），由你定。

### C. 被挡住时显示 Yui 的轮廓

- 她走到墙后、家具后（比如墙全立时、被沙发靠背或台灯挡住时），被挡住的部分画成一层淡色剪影，加描边。没被挡住的部分照常显示。
- 实现：画完场景后，用同一个深度缓冲把她再画一遍，只画「在别的东西后面」的像素（深度比较反过来）。颜色跟着画风走（lofi 和原画风各一套）。
- 只给 Yui 用，家具和外景不用。

### D. 顺带修好的

- **「看看她」近景不再穿墙**：近景时，挡在镜头和她之间的墙直接切掉，被家具挡住时用 C 的轮廓。
- **房间之间走动**：她的作息要能走进新房间（新的路线点、门洞），可以加几项新的日常（早上去洗漱、晚上洗澡后回卧室、白天晾衣服等）。新加的动作只用宿主已有的动作文件，缺的先用站着或坐着代替。

## 3. 影响和风险

- **室内会变暗**：四面有墙后，阳光只能从窗户进来。灯光、环境光、阴影都要重新调。lofi 画风要单独看。
- **帧率**：墙、家具、房间多了，阴影和 GTAO 的负担会上升。按通用标准（30 帧、超过 33 ms 降档）重新验证自动画质，不按本机调。
- **画面的阅读方式变了**：以前一眼就能看到整层。改成完整房子后，要靠转镜头、切墙来看。总览的默认角度要重新选。
- **改动面大**：会动到这些地方：
  - `cottage-layout.mjs`（房间、墙）、`cottage-house.mjs`（画墙、家具）；
  - `cottage-scene.mjs`、`cottage.mjs`（镜头、切墙、轮廓、房间菜单）；
  - `cottage-routine.mjs`、`cottage-yui-life.mjs`（路线、作息）；
  - `cottage-grounds.mjs`（前院）；
  - 规则测试和小屋浏览器测试里关于房间、路线和镜头的断言。
- **存档**：小屋物件槽位（墙上的画、日历等）的编号不变，不会丢摆放。新房间的槽位是新加的。

## 4. 建议的顺序（每步一个版本，做完一步给你看）

1. **灰盒布局**：用 `tools/preview/cottage-blockout.mjs` 把新加的一排房间搭成灰盒，截几张不同角度的图给你定房间和大小。按 AGENTS.md，新素材先出概念图；这一步就是概念图。
2. **补墙和切墙、360° 镜头**：先在现有大小上补上前墙，做好三档墙模式和自动切墙，镜头放开 360°。这一步做完，现有房间就已经是「完整房子 + 透视看」了。
3. **新的一排房间和家具**：按第 1 步定下的布局建房间、放家具，前院让位。
4. **Yui 的轮廓**。
5. **Yui 走进新房间**：路线、作息、新日常；「看看她」近景配合切墙。
6. **灯光和画质复核**：室内光、lofi 画风、自动画质。

第 2 步和第 4 步彼此独立，也可以先做第 4 步。
