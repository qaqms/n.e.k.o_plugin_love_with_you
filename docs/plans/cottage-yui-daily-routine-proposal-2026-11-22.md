# Yui 的一天：在屋里走动、按作息生活（方案，待项目主人选择）

项目主人的想法：让 Yui 在屋里来回走，像人一样过一天，比如晚上走到卧室睡觉，早上做饭、吃饭。

这是之前说的「方向 C」（让她走动），属于大方向，先给方案。

## 1. 现在有什么

- **房子**：一楼客厅、厨房、门廊小院，二楼卧室、阁楼书房。楼梯在厨房右墙边，从前往后上到书房。已有的家具：床（卧室）、冰箱、料理台、两人餐桌（厨房）、沙发、茶几（客厅）、门廊长椅、书桌（书房）。
- **动作**：宿主的动作库 `static/vrm/` 里有 75 段动作，许可都是 Apache-2.0（来自 Overte，宿主已附署名说明）。这次能用上的有：
  - 走路：`world-walk`（一步一秒的走路循环）
  - 坐：`双脚平放端正地坐`、`休闲地盘着腿坐`
  - 躺 / 睡：`趴着安静熟睡轻微呼吸`、`趴着睡梦中翻动身体`、`侧着身子慵懒地躺下`
  - 起床前后：`困倦地抬手打哈欠`、`开心地舒展身体`、`从低姿态撑起身体站好`
  - 其他日常：`站着用手操作平板电脑`、`坐着用双手敲击键盘`
  - **没有**：做饭、吃饭、上下楼梯。
- 之前项目主人确认过宿主的动作可以随插件发布（`static/models/motion/README.md`）。

## 2. 难点

1. **做饭、吃饭没有现成动作和道具**：动作可以在站着、坐着的动作上用代码叠加手臂动作（搅拌、翻锅、夹菜往嘴边送），像现在抚摸的反应那样；道具（锅、碗、盘子、食物）是新的一类美术素材，按约定**先出概念图**。
2. **上下楼梯**：没有爬楼梯动作。可以让走路动作沿楼梯斜着走（脚会有一点滑），或者走到楼梯口淡出、在楼上淡入。
3. **裙子**：走路时裙摆已经有腿部防穿模；坐在沙发、椅子上和躺在床上时，裙子和家具之间没有碰撞，可能会穿进去。
4. **互动要跟着她走**：现在点她、推近、抚摸都假设她站在客厅地毯上。她在别的房间时，镜头和卡片要去她所在的位置；她睡着时摸她，要有「迷迷糊糊」的反应。
5. **看不见她的时候**：你在客厅视角而她在厨房，就看不到她。需要告诉你她在哪（比如房间菜单上标「Yui 在厨房」，或者进小屋时镜头直接去她在的房间）。
6. **性能**：她走动时要一直重画画面，比现在静止时更耗电。

## 4. 方案

| 方案 | 做什么 | 工作量 | 问题 |
| --- | --- | --- | --- |
| **A. 按时段换位置，不走路** | 到点她就出现在对应的地方、做对应的动作（睡觉、坐沙发、在厨房），换地方时淡出淡入 | 小 | 看不到「走过去」，像换场景 |
| **B. 同一层真走路，上下楼淡出淡入**（建议） | A 的全部 + 同一层里沿门口走过去（比如客厅走到厨房），上下楼在楼梯口淡出、在楼上淡入；做饭、吃饭用代码叠加的手臂动作 + 简单道具 | 中 | 做饭吃饭要先出道具概念图；坐、躺时裙子可能穿进家具 |
| C. 全部真做 | B + 沿楼梯真的走上走下、做饭有多个步骤和道具、你可以和她一起做饭吃饭 | 大 | 楼梯动作要自己做；一起做饭是新玩法，要另外设计 |

**建议 B，分三步做**，每步做完给你试：

1. **作息和走路**：作息表、按时间决定她在哪、同层走路（沿门口的路线）、楼梯口淡出淡入、睡觉（床上）、起床打哈欠伸懒腰、坐沙发。点她时镜头去她所在的位置；房间菜单标出她在哪个房间。
2. **做饭、吃饭**：先出锅碗盘子和食物的概念图，你确认后做；手臂动作用代码叠加。
3. **睡着时的互动、让桌宠知道她在干什么**：睡着时摸她是迷迷糊糊的反应；抚摸和邀请聊天时，提示里告诉桌宠她正在做什么（比如「你正在厨房做饭」）。

## 5. 需要你决定的

1. **哪个方案？**（建议 B）
2. **时间跟什么走？** 建议跟电脑时钟（和小屋的「自动」时段一致），手动选时段时跟选的时段。
3. **进小屋时，镜头要不要直接去她在的房间？** 建议要：不然夜里进来，客厅是空的。
4. **她睡着时能不能摸、能不能叫醒？** 建议能摸，她迷迷糊糊地回应，不会真的起床；「说说话」在她睡着时改成「轻声说晚安」之类。
5. **你在看她时，她要不要停下来？** 建议：你点了她（推近）时，她停下手上的事，转过来；你退出后她接着做。
6. **桌宠知道她在做什么要不要放在第一步？** 建议放第三步，先把画面做好。

## 6. 项目主人的决定（2026-11-22）

1. **方案 B**，先做 B，之后再补齐 C（真走楼梯、做饭多步骤和道具、一起做饭吃饭）。
2. **时间跟小屋自己的时间走**：时段选「自动」时跟电脑时钟；手动选了白天、黄昏或夜里时，她做那个时段里的事（时间在那个时段里照样往前走）。
3. **进小屋时镜头是总览**。
4. **镜头记住上次离开时的位置**（房间视角和转过的角度），回到小屋时还是那样；软件重启后不用记，重新从总览开始。
5. **睡觉时可以叫醒她**。
6. **看她时不打断她**；**点了她、要互动时才打断**她手上的事。

第一步按这些决定做在 0.9.40，见 `docs/adventure/adventure-cottage-yui-2026-11-21.md`。
