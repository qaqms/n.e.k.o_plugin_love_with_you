# 项目目录整理（0.9.0，原开发编号 0.12.4）

2026-11-16 按项目主人要求将当前插件发布版本号由 `0.12.4` 调整为 `0.9.0`，同步 `plugin.toml`、`pyproject.toml` 和当前使用说明，重新生成导入包。历史开发编号与下述既有验证记录保留，玩法和存档版本不回退。当前源码目录接入 `qaqms/n.e.k.o_plugin_love_with_you` 的 `main` 历史，提交不包含归档、开发环境和导入包，不自动发布 Git 标签。

本次只整理插件源码、工具、文档和开发产物。宿主目录、安装目录、真实存档和资源 URL 不变，战斗规则仍为 12，存档格式仍为 13。

## 结构

根目录普通文件从 28 个减至 8 个，保留 `__init__.py`、README、AGENTS 和项目配置。19 个业务模块分入 `backend/relationship/`、`backend/adventure/`、`backend/infrastructure/`。宿主仍通过 `plugin.plugins.love_with_you:LoveWithYouPlugin` 加载原入口；生命周期、锁和动作编排留在该入口。

`backend/paths.py` 统一提供资源根目录，技能和旅程数据继续读取原来的 `static/*.json`，避免移动模块后按错误位置找资源。测试与预览同步使用新的包路径。

工具按 `build/`、`preview/`、`assets/`、`development/`、`tests/` 分组，npm 命令保持统一入口。游戏规则测试使用发布目录中的 A* 库。游戏记录放在 `docs/adventure/`，审计放在 `docs/audits/`，方案放在 `docs/plans/`，架构沿革从根目录移至 `docs/architecture.md`。

备份、截图和基准数据放在 `archive/`，历史导入包移到 `dist/archive/`。归档从构建、开发副本、lint 和 Git 中排除。整理前备份为 `archive/backups/0.12.3-structure-20261116/`，原路径映射在 `archive/maintenance/layout-20261116.json`。
