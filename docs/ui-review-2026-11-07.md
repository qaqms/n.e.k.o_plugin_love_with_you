# UI 审查与优化记录

日期：2026-11-07。范围：插件 `ui/panel.tsx`、立绘资源、翻译文件及与宿主 Hosted UI 的交互契约。宿主源码未修改。

## 发现与处理

| 优先级 | 原有问题与触发条件 | 本轮处理 |
| --- | --- | --- |
| P1 | 称呼编辑时，后台昵称刷新或切换角色会替换草稿，未保存内容丢失 | 草稿按 scope 保留；干净表单跟随后台更新，脏表单保持编辑内容；新增未保存提示与撤销 |
| P1 | 后端保存成功但 `api.refresh()` 失败时，界面把整个操作报成失败，鼓励重复提交 | 分离动作与刷新结果；成功操作正常结束，刷新失败展示独立重试入口 |
| P2 | 宿主 Modal 依赖 `onClose` 回调；内联回调随每次输入变化，导致反复执行首次聚焦 | 所有编辑弹窗使用稳定关闭回调；关闭后恢复触发按钮焦点 |
| P2 | 保存过程中仍能按 Escape、取消或点遮罩关闭，部分控件可继续编辑 | 保存时禁止关闭和编辑；同步请求锁拦截重复提交，保存失败保留输入 |
| P2 | 桌面侧栏收起后所有页面入口消失；390px 窗口常驻侧栏占 100px | 收起后保留五个图标入口，700px 以下自动使用 56px 图标导航 |
| P2 | 各页长期为立绘预留右栏，设置和编辑页面的正文空间不足 | 大立绘只用于概览，设置提供小图预览；其余页面使用完整正文宽度 |
| P2 | 已有成功评分时，后续评分失败被旧成功统计遮住 | 优先展示当前总线或评分错误，增加非成功状态的视觉标记 |
| P2 | 日期表单的可见标题未绑定输入框；相识日可选未来日期；数值调整只能拖滑块 | 使用关联 label、原生日期上下界和真实日期校验；好感调整加入数字输入并保留滑块 |
| P3 | 图库已有不可解码的图片缓存时，重试会再用同一份坏缓存；首次切固定模式可进入空选择 | 图片解码失败清缓存，错误提供反馈；无固定图片时先打开图库选择 |
| P3 | 页面缺少完整深色配色，趋势选择状态与图表信息不便于辅助技术读取 | 增加深浅主题变量、加减分辅助色；趋势按钮报告选中状态，图表报告摘要，删除按钮包含纪念日名称 |

保留了五页结构、粉色主色、好感圆环和原有立绘素材。没有改变评分、关系规则或持久化协议。

## 验证

- 使用宿主原有 `hostedTsxModule.mjs`、`ui-kit/runtime.js` 和 `styles.css`，由 Sucrase 编译实际插件 TSX；没有用 React 替代宿主渲染器。
- 13 项 Chromium 浏览器测试涵盖五页在六种窗口宽度和深浅主题下的布局，侧栏、草稿、动作失败重试、刷新失败、保存锁、日期输入焦点和边界、图库筛选与分页、图片损坏重试、评分错误、空角色及多语言长名称。
- SDK 类型检查通过；8 个语言包均包含本轮新增提示，现有翻译的插值参数检查通过。
- 原有 343 项 Python 测试和 Ruff 检查通过。
- 浏览器截图位于仓库外 `.neko-ui-review/artifacts`；`tools` 下保留了预览、类型检查、图标生成和回归脚本。Lucide 图标以小型静态子集随 UI 打包，保留原始许可证。

## 剩余范围

- 尚未在运行中的 N.E.K.O 中验证真实插件 iframe 的生命周期、后台数据推送和设备缩放；浏览器验证使用真实宿主控件及独立模拟数据，不等同于完整宿主联调。
- 简中和英文翻译完整；繁中、日文、韩文、俄文、西语、葡语原有翻译只覆盖部分界面，其余内容会按宿主策略回退。未在本轮扩展为全量翻译。
- 草稿只存于当前面板内存，关闭面板后会丢弃，未增加聊天或草稿的磁盘存储。

## 第二轮：阅读与反馈体验

本轮在主题配色功能基础上继续审查五页 UI。保留现有素材与五页结构，只修改插件 UI、翻译和开发验证工具。

| 优先级 | 发现 | 处理 |
| --- | --- | --- |
| P1 | 弹窗保存失败仅显示页顶错误和短时 Toast，局部提示可能被遮罩遮住 | 弹窗页脚持续显示失败原因；输入保留，可直接重试；其他页面在底部显示持续状态 |
| P2 | 所有保存按钮共用 busy 文案，刷新阶段仍只显示“保存中”，难以确认操作是否成功 | 按动作显示按钮状态，反馈区区分提交、操作已完成但正在刷新、具体成功结果，以及已保存但显示未更新 |
| P2 | 设置页连续滚动较长，自动判断和主动告白的长说明增加阅读负担 | 增加顶部固定分区入口与焦点定位；长规则折叠，关键影响和禁用条件保持可见 |
| P2 | 称呼和纪念日名称按 UTF-16 单元截断，会切坏边界处的 emoji，且与后端字符限制不同 | 按 Unicode 码点截取和计数；称呼输入增加长度提示 |
| P3 | 概览缺少最近变化入口，称呼和外观的保存按钮与编辑区域较远 | 概览增加最近记录及完整记录入口；两个表单统一采用底部修改状态和保存操作区 |
| P3 | 概览立绘加载失败时只有设置页能看到错误和重试 | 概览也显示图片失败提示和独立重试，不必离开当前页面 |
| P3 | 错误、警告和危险操作沿用宿主色值，对比度不足 | 补齐深浅主题语义色；统一正文行高、说明字号和内容宽度；危险操作使用明确的文字颜色 |

### 本轮验证

- 366 项 Python 测试、24 项 Chromium UI 测试和 4 项配色测试通过；SDK 类型、多语言插值和 Ruff 检查通过。
- 新增回归覆盖 320px 窄窗口的弹窗失败、慢提交及慢刷新、保存成功后刷新失败、提示可见性、页面节点及滚动保留、弹窗关闭及提示关闭后的焦点恢复、设置分区与折叠说明、Unicode 名称边界。
- 深浅主题覆盖五页和 320 / 390 / 700 / 800 / 980 / 1440px 布局；配色检查额外验证正文、次要文字、错误和警告在三种背景上的对比度。
- 验证中发现并修正了新增最近记录在窄窗口的排序、反馈插入导致宿主渲染器重建页面节点、固定分区栏遮住目标标题，以及 800px 下提示遮挡底部操作的问题。
- 浏览器继续使用真实宿主渲染器与模拟数据，未进行运行中宿主的完整联调。

## 第三轮：指针与操作反馈

日期：2026-11-07。范围：插件 UI 交互、主题变量、反馈生命周期和浏览器回归。宿主源码及经济、好感度规则均未修改。

- 导航、按钮、主题色、图库选择和折叠入口统一使用轻量悬停提示、即时按压和 180ms 的释放确认；不改变控件坐标、尺寸或触发区域。
- 原生事件负责实际操作，插件只监听反馈。拖出、取消指针、滚动、窗口失焦和键盘释放清理按压状态，快速重复操作替换旧动画。
- 触屏不继承鼠标悬停效果；键盘保留焦点和按压反馈；减少动态效果模式取消过渡、释放动画与加载旋转。
- 实际请求单独标记触发控件的忙碌状态，已有同步请求锁、请求重放与成功判定保持原逻辑。购买和赠送仍等待接口确认。
- 保存按钮为普通文案、处理中和图标预留稳定尺寸；赠送确认将“正在赠送”和“确认上次操作”分开呈现。
- 开关等待期间保持请求目标的视觉状态；失败或取消确认后恢复保存值，兼容宿主仅更新变化属性的原生 checkbox 行为。
- 成功提示按文字长度在 6 至 12 秒后淡出，悬停、聚焦或页面隐藏时暂停；错误、警告及处理中提示持续保留。保留常驻反馈插槽，避免宿主重建页面、丢焦点或改变滚动。
- 新增 9 项浏览器回归覆盖真实按下与释放、取消路径、键盘及触屏、减少动态效果、请求中按钮尺寸、开关回退、提示暂停与自动收起、快速操作和错误保留。
- 最终 46 项浏览器测试与 4 项主题测试全部通过；5 个 UI 文件的 SDK 类型检查及 8 种语言的插值检查通过，已检查深浅色按压截图。

浏览器仍使用真实宿主渲染器与模拟业务数据；实际宿主窗口和设备手感需在重载插件后体验。
